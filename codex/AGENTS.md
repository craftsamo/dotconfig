## Skill authoring

When the user explicitly asks to create or update an Agent Skill, skill
directory, or `SKILL.md`, load and follow the shared `skill-authoring` Skill.
Do not load or combine the system `skill-creator` for that request. Do not use
either Skill merely because a workflow appears repetitive.
