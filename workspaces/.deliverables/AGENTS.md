# .deliverables

Fallback chat-delivery staging for unassigned or intentionally cross-group work. A
single-Group artifact belongs in that Group's `.agent/deliverables/<job>/`. Deliver
with a bare `MEDIA:/abs/path` line so the gateway attaches the file natively. Keep
filenames clean; clear only the current job after the user accepts it, not immediately
after send. Do not sweep historical entries while migrating the layout.
