# Production translation

Read when an expression must become a producer request or when accepted parts
must form a coherent composite. This is craft translation, not a tool dispatcher.

## Describe an observable, not only a setting

"Perspective 4000" describes a parameter. "The underside remains visible while
the next panel is revealed" describes the result the parameter must serve. Both
can be useful, but the latter lets a producer discover that a numerically correct
implementation still misses the intention.

For each uncertain unit, carry its purpose, proposed mechanism, protected input
and success evidence. Leave implementation choices with the actual producer
unless the client fixed them. Do not write coordinate scripts for a producer
whose responsibility is to author a layout or timeline.

Before asking for approval, identify what is known about feasibility. Separate a
template default, a missing input, an inaccessible reference, an environment
failure and a true backend limit. A valid schema does not prove that fonts,
assets, render features or voice controls will survive later validation. Run only
the host's permitted, non-production preflight at this stage.

## Test the uncertainty, not a miniature checklist

A representative study should answer the risky question: does the silhouette
read, does the transition communicate a change, does a vocal delivery reassure?
It need not reproduce every feature of a final advertisement. However, a study
is still production: it needs its own explicit host release, shares applicable
attempt accounting, and cannot bypass a zero-production proposal stage.

Use the current supported study path. If none fits, report the narrow gap rather
than adding placeholder CTA text, silently changing the subject, or calling a
renderer outside the producer's contract. A successful study is not final-media
approval. Exact final approvals remain the host's job.

## Composite responsibility

Keep accepted text, visuals, audio and timing as identifiable versions. A new
spoken sentence may invalidate captions and timed graphics; a color adjustment
usually need not invalidate narration. Recheck affected relationships rather
than restarting every component. A locally strong part can still be wrong in
the whole: a busy melody under an important explanation, or an intricate mascot
beside a tiny label, can defeat the shared hierarchy.

## Worked case: the disappearing panel

**Request.** Show one task panel becoming a compact summary while a result opens.

**Weak handoff.** Specify scale, duration and blur, then accept screenshots only
at the beginning and end. The outgoing panel disappears between them.

**Diagnosis.** End-state fidelity left the relationship untested. The transition
was the communication, not a disposable flourish.

**Revision.** Carry the intended identity continuity and ask the producer to
show the interval where the panel becomes the summary. Let it choose an
appropriate carrier and timing within the approved look. Inspect representative
intermediate frames as well as normal-speed playback when available.

**Retain.** Preserve approved UI labels and actual product state changes. An
illustrative transition must not imply a feature the product does not have.

## Worked case: a musical logo masks a name

**Request.** A brief spoken organization name should land over a finished sonic
mark. The supplied voice and mark must not be regenerated.

**Weak handoff.** Place both at their loudest moment and ask the mixer to make
each stand out. Meters stay below clipping, but the listener misses the name.

**Diagnosis.** The parts have no agreed foreground relationship. Technical
headroom is not perceptual space.

**Revision.** Propose changing placement or an allowed gain envelope so the
name receives a clear interval before the mark resolves. If exact timing is
also fixed and no supported processing can meet it, return that conflict rather
than inventing EQ or a new voice take.

**Evidence.** Listen to the whole short sequence, not isolated stems. Preserve
original sources and distinguish a review copy from the approved final master.

## When not to expand the work

An exact crop or trim with settled bounds needs no creative decomposition. A
known composition with a single typo does not need a new concept study. Preserve
the smallest scope that can satisfy the actual request.
