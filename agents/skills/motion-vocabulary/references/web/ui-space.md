# Interface space and material: web builds

How each entry of [../ui-space.md](../ui-space.md) is built on a real web page: the trigger that starts it (load, enter view, scroll progress, hover, focus, press, drag, state or route change), the smallest tool that builds it (CSS, then the Web Animations API, then a library) and what replaces it under `prefers-reduced-motion: reduce`. Read the entry's Looks like and The tell first. Typical values here come from common web practice; a project's own motion tokens win.

How an interface changes place and surface on a real page: layout and route changes, overlays, depth, material and 3D, plus view and page transitions. Default tool for view changes: the View Transitions API, same-document (`document.startViewTransition(() => update())`) or cross-document (`@view-transition { navigation: auto; }` in both pages). Where unsupported, run the state update directly with no animation, or a plain CSS opacity transition. Reduced-motion default: `@media (prefers-reduced-motion: reduce)` sets `::view-transition-group(*), ::view-transition-old(*), ::view-transition-new(*) { animation-duration: 0.01ms; }` or a short fade. Hover effects sit inside `@media (hover: hover)` with a `:focus-visible` or tap equivalent. Features that are not in every engine (anchor positioning, `interpolate-size`, `::details-content`, CSS `d: path()`) are used behind `@supports` with the fallback named in the row.

## Layout and navigation

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| shared element（共有要素トランジション） | route change | `view-transition-name: hero` on the thumbnail in the old state and on the detail image in the new state (only one element per page carries it; clear it on the other), update inside `startViewTransition`; cross-document with `@view-transition { navigation: auto; }`. Tune `::view-transition-group(hero) { animation-duration: 450ms; animation-timing-function: cubic-bezier(.65,0,.35,1); }`. No support: swap instantly, or FLIP with `transform` and `clip-path`. Library: Motion `layoutId` (also across routes). | Instant swap or 150ms opacity fade; no travel. |
| view crossfade（ビュークロスフェード） | state change | Default View Transition: `document.startViewTransition(update)` gives a root crossfade; set `::view-transition-old(root), ::view-transition-new(root) { animation-duration: 300ms; }`. Fallback: apply the update with `opacity` transition on the container. | same — no travel |
| FLIP reorder（FLIP並べ替え） | state change | FLIP: read `getBoundingClientRect()` before and after the DOM reorder, set `transform: translate(dx, dy)` inverse, then `el.animate([{transform: 'none'}], {duration: 400, easing: 'cubic-bezier(.65,0,.35,1)'})` from the inverted offset. Or `view-transition-name` per item. Motion `layout` does it automatically. Avoid animating `top`/`left`. | Reorder instantly. |
| modal morph（モーダルモーフ） | press | Only one element may carry `view-transition-name: dlg` at capture time: set it on the trigger, call `startViewTransition`, and inside the update callback clear the trigger's name and give it to the dialog while `dialog.showModal()` runs (swap back on close); the group animates box and radius. Fallback: FLIP with `element.animate` on `transform: scale()` and `clip-path: inset(... round r)` over 400ms; scrim `opacity`. | Dialog appears with a 120ms fade; no growth. |
| tab indicator（タブインジケーター） | press | One absolutely positioned bar; on click set `transform: translateX(x) scaleX(w/base)` with `transition: transform 250ms cubic-bezier(.22,1,.36,1)`; or give the bar `view-transition-name: tab` and move it in the DOM; Motion `layoutId` also works. | Jump to the tab with no slide. |
| filter reflow（フィルター再配置） | press | Step 1: `opacity: 0; scale: .9` transition 200ms on removed cards; step 2: FLIP the remaining cards (record rects, apply, animate `transform` to none, 350ms). With View Transitions give each card a unique `view-transition-name` and filter inside `startViewTransition`. | Cards removed and re-laid instantly. |
| route slide（ルートスライド） | route change | `::view-transition-old(root) { animation: slide-out-left 300ms cubic-bezier(.22,1,.36,1); }` and `::view-transition-new(root) { animation: slide-in-right ... }` with `@keyframes` on `transform: translateX(...)`, old moving 30% and dimming; flip direction with a class set before `startViewTransition`. Cross-document via `@view-transition`. Fallback: no animation. | Plain 150ms crossfade, no sideways travel. |
| page wipe（ページワイプ） | route change | Fixed full-height panel animated `transform: scaleX(0 to 1)` with `transform-origin: left`, 350ms `cubic-bezier(.7,0,.3,1)`; run the navigation or state swap at full cover, then `transform-origin: right` and `scaleX(0)`. Or `::view-transition-new(root)` with `clip-path` keyframes. | Swap instantly; no panel. |
| sidebar reveal（サイドバー展開） | press | Panel `transform: translateX(-100%)` to `0`, 280ms `cubic-bezier(.22,1,.36,1)`, toggled by a class; scrim `opacity` 0 to .4 with a 40ms delay; panel as `<dialog>` or `popover` with `[popover]:popover-open { @starting-style { translate: -100% 0; } }` for entry. | Panel appears with a 100ms fade; no slide. |
| command palette open（コマンドパレット展開） | press | `<dialog>` opened with `showModal()`; `dialog[open] { @starting-style { opacity: 0; transform: translateY(-8px) scale(.97); } }` with `transition: opacity 160ms, transform 160ms, overlay 160ms allow-discrete, display 160ms allow-discrete;` rows staggered with `transition-delay: calc(var(--i) * 25ms)`. | Opens with opacity only; rows appear together. |
| dropdown origin reveal（ドロップダウン起点展開） | press | Menu `transform-origin: top left` (set from the trigger corner), `scale: 1 .9` and `opacity` to 1 in 160ms `cubic-bezier(.2,.8,.2,1)`; use `popover` plus anchor positioning (`position-anchor`) inside `@supports (anchor-name: --a)` (fallback: JS-measured or `position: fixed` placement from the trigger rect) and `[popover]:popover-open { @starting-style { opacity: 0; scale: .9; } }`; items stagger 20ms top to bottom. | Fade only, 100ms. |
| list-to-detail expand（一覧から詳細展開） | route change | Selected row `view-transition-name: item`, moved to the detail container inside the update callback (never on both at capture time); other rows get `view-transition-class` fade. Fallback FLIP from the row rect to the full viewport, `transform` and `clip-path`, 450ms `cubic-bezier(.65,0,.35,1)`. | Detail shown instantly or with a fade. |
| popover enter and exit（ポップオーバー出入り） | press | `[popover]:popover-open { @starting-style { opacity: 0; scale: .9; } }`, `transform-origin` at the anchor corner, `transition: opacity 150ms, scale 150ms, display 150ms allow-discrete, overlay 150ms allow-discrete;`; the closed state is the same reversed. | Opacity only. |
| top layer dialog（トップレイヤーダイアログ） | press | `dialog[open] { opacity: 1; translate: 0 }` with `dialog[open] { @starting-style { translate: 0 16px; scale: .96; } }`, 320ms ease-out; `dialog::backdrop` transitions `background-color` over 450ms; `allow-discrete` on `display` and `overlay`. | Backdrop and dialog fade, no rise. |
| circular view transition（円形ビュー遷移） | press | Store click x/y, `startViewTransition(update).ready.then(() => document.documentElement.animate({clipPath: ['circle(0 at X Y)', 'circle(R at X Y)']}, {duration: 500, easing: 'cubic-bezier(.65,0,.35,1)', pseudoElement: '::view-transition-new(root)'}))` where X Y are the click px and R is the distance to the farthest corner (`Math.hypot`); set `::view-transition-old(root), ::view-transition-new(root) { animation: none; mix-blend-mode: normal; }`. Fallback: no animation. | Instant swap. |
| discrete property exit（離散プロパティ退場） | state change | `transition: opacity 200ms, scale 200ms, display 200ms allow-discrete;` with `.gone { opacity: 0; scale: .9; display: none; }`; the neighbours' shift via FLIP or a `grid-template-rows: 1fr to 0fr` transition. Fallback: set `display: none` on `transitionend`. | Removed instantly. |
| intrinsic height expand（自動高さ展開） | press | `@supports (interpolate-size: allow-keywords) { :root { interpolate-size: allow-keywords; } }` then `transition: height 300ms ease-out` from `0` to `auto`. Fallback: measured pixel height from `scrollHeight`, or `display: grid; grid-template-rows: 0fr` to `1fr` transition on the wrapper with an inner `overflow: hidden`; for `<details>` use `::details-content` with `content-visibility` only inside `@supports selector(::details-content)`, otherwise open instantly. | Open at once. |
| page stack transition（ページスタック遷移） | route change | `::view-transition-new(root) { animation: rise 400ms cubic-bezier(.65,0,.35,1); }` from `translateY(100%)`; `::view-transition-old(root)` animates `scale: .94; filter: brightness(.7)`; `z-index` so the new is on top. | Crossfade only. |
| modal enter / exit（モーダルを開く・閉じる） | press | `dialog { transition: opacity 120ms ease-in, scale 120ms ease-in, display 120ms allow-discrete, overlay 120ms allow-discrete; }`, `[open] { transition-duration: 280ms; transition-timing-function: cubic-bezier(.22,1,.36,1); }`, `dialog[open] { @starting-style { scale: .96; opacity: 0; } }`; scrim in step. | Opacity only. |
