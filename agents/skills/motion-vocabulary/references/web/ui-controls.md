# Interface controls: web builds

How each entry of [../ui-controls.md](../ui-controls.md) is built on a real web page: the trigger that starts it (load, enter view, scroll progress, hover, focus, press, drag, state or route change), the smallest tool that builds it (CSS, then the Web Animations API, then a library) and what replaces it under `prefers-reduced-motion: reduce`. Read the entry's Looks like and The tell first. Typical values here come from common web practice; a project's own motion tokens win.

Motion for real page controls: hover, focus-visible, press and drag states, toggles, forms, loaders, toasts and reactions. Touch screens have no hover, so each hover effect needs a touch equivalent (`:active`, a tap state or a plain static state), and focus rings stay visible: never remove `outline` without a replacement, and wrap hover-only styling in `@media (hover: hover)`.

## Web interaction

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| hover lift（ホバーリフト） | hover, focus | `transition: transform 150ms cubic-bezier(.2,.8,.2,1), box-shadow 150ms` to `translateY(-4px)` plus a bigger shadow, inside `@media (hover: hover)`; mirror on `:focus-visible`; on touch use `:active` only. Shadow repaints, so fade a pseudo-element's opacity if it janks. | Drop the translate; keep a shadow or border colour change, no travel. |
| magnetic button（マグネティックボタン） | hover | `pointermove` on a padded wrapper sets `translate` to about 0.3 x the offset from centre, clamped to 12px, via CSS variables; on `pointerleave` reset with `transition: translate 400ms cubic-bezier(.22,1,.36,1)`. Pointer-type fine only; none on touch. | Remove the effect entirely; the button stays put. |
| pointer tilt（ポインターチルト） | hover | Parent `perspective: 800px`; on `pointermove` set `rotateX`/`rotateY` up to 8deg from the normalised offset, applied in `requestAnimationFrame`; reset with a 300ms ease on leave. Touch: no tilt, or tie it to `deviceorientation` only if asked. | Disable tilt; keep a flat hover shadow or outline change. |
| cursor follow（カーソル追従） | hover | Fixed-position elements moved with `translate3d`; each follower lerps toward the pointer in a `requestAnimationFrame` loop (factor 0.15, 0.1, 0.06) with `pointer-events: none`. Hide on `(hover: none)`. Keep the real cursor visible. | Hide the followers; use the native cursor only. |
| drag inertia（ドラッグ慣性） | drag | Pointer events with `setPointerCapture`; track velocity over the last ~100ms, then continue with a per-frame decay (`v *= 0.95`) or Motion's `drag` with `dragTransition={{ power: 0.3, timeConstant: 300 }}`; clamp to bounds, `touch-action: none` on the handle. | Release stops the item where the pointer let go; no coasting. |
| click ripple（クリックリップル） | press | On `pointerdown` append a span at the pointer coordinates inside a button with `overflow: hidden; position: relative`; animate `transform: scale(0 to 4)` and `opacity: .35 to 0` over 450ms `ease-out`, then remove it. Works for touch taps and keyboard (centre origin). | Replace with an instant background tint that fades out in 150ms; no spread. |
| toggle morph（トグルモーフ） | press, state change | `<button role="switch" aria-checked>`; knob `translate` 250ms `cubic-bezier(.34,1.56,.64,1)` with a `scaleX(1.3)` keyframe at 50%; track `background-color` transition. Use `:focus-visible` outline on the switch. | Knob and colour change instantly or in 100ms; no stretch or overshoot. |
| accordion open（アコーディオン展開） | press, state change | `<details>` or button plus panel; `interpolate-size: allow-keywords` inside `@supports (interpolate-size: allow-keywords)` and `transition: height 300ms ease` from `0` to `auto` (fallback: measured `scrollHeight`, or grid-template-rows `0fr` to `1fr`); chevron `rotate(180deg)` in step. Keep `aria-expanded`. | Open and close instantly; chevron swaps without turning. |
| button fill hover（ボタン塗りホバー） | hover, focus | A `::before` with `transform: scaleX(0)` and `transform-origin` set from the entry side (JS sets a class by pointer x), transition to `scaleX(1)` in 250ms `ease-out`; label `color` transition delayed ~100ms. On touch show the filled state on `:active`. | Instant colour swap on hover and focus-visible; no sweep. |
| icon morph（アイコンモーフ） | press, state change | Three bars with `transition: transform 250ms ease-in-out`: top `translateY(7px) rotate(45deg)`, middle `scaleX(0)` with opacity 0, bottom `translateY(-7px) rotate(-45deg)`, driven by `aria-expanded`. Or SVG path morph with equal point counts (Motion or GSAP MorphSVG). | Swap the two icons instantly or with a 100ms opacity fade. |
| card spotlight（カードスポットライト） | hover | `pointermove` writes `--x` and `--y` in px onto the card; background `radial-gradient(300px circle at var(--x) var(--y), rgba(255,255,255,.15), transparent 60%)` on a pseudo-element; fade opacity in on `pointerenter`. Hover-capable devices only. | Static faint gradient or border highlight; no tracking. |
| drag snap（ドラッグ吸着） | drag | `pointermove` moves via `translate`; on `pointerup` pick the nearest slot by distance and animate with WAAPI `element.animate` 300ms `cubic-bezier(.34,1.56,.64,1)` or Motion `animate`; highlight the slot on `:focus-visible` or hover. Offer a keyboard alternative. | Jump straight into the slot with no overshoot. |
| card stack fan（カードを広げる） | press, state change | Cards share `transform-origin: 50% 100%`; on open set `rotate(calc(var(--i) * 8deg - 16deg))` and `translateX` with `transition-delay: calc(var(--i) * 40ms)` on `cubic-bezier(.34,1.56,.64,1)` (spring via `linear()` also works). | Cards appear fanned instantly, or with a 150ms opacity fade; no rotation travel. |
| tooltip（ツールチップ） | hover, focus | `role="tooltip"` on hover and `:focus-visible` (not hover-only); `.tip { @starting-style { opacity: 0; scale: .95; } }` or a class: `opacity` and `scale(.95 to 1)` over 150ms `ease-out` with `transform-origin` at the arrow, exit 80ms. Touch: show on focus or long-press. | Opacity fade only, no scale. |
| human cursor path（カーソルは弧を描いて動く） | time | A real page has no scripted cursor; use it only in a guided demo: a fake cursor on an SVG path with CSS `offset-path: path(...)` and `offset-distance` 0% to 100% over 900ms `ease-in-out`, then a 200ms hold and a click class. | Skip the demo travel; show the end state of the click directly. |

## UI buttons

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| bounce press（バウンスプレス） | press | `:active { scale: .94 }` then release with a WAAPI keyframe `scale` 0.94, 1.08, 0.98, 1 over 400ms, or a `linear()` spring easing; applies to touch taps too. | Only a brief `:active` colour change; no scale. |
| jelly squash（ジェリースカッシュ） | press | Keyframes on release: `scale: 1.2 .8`, `.9 1.1`, `1.05 .95`, `1` over 500ms; `scale` is paint-free. Use `transform-origin: bottom` if it should stay grounded. | Skip the wobble; `:active` colour tint only. |
| tap ripple（タップリップル） | press | `pointerdown` places a span at `offsetX/offsetY`, scales 0 to 3 while opacity fades over 500ms, clipped by `overflow: hidden`; the button gets a 150ms `scale(.97)` keyframe. | Tint flash only; no ring, no dip. |
| pulse glow（パルスグロー） | loop | A blurred `::after` (`filter: blur(8px)`) with `@keyframes` on `scale` 1 to 1.3 and `opacity` .6 to 0, 2s `ease-in-out`, `animation-iteration-count: 3`. | Remove the loop; keep a static glow or `box-shadow`. |
| fill sweep（フィルスイープ） | press, state change | A `::before` `scaleX(0 to 1)` from `transform-origin: left` over 350ms `ease-in-out` on a state class; label `color` transition in step; no reverse. | Instant new colour. |
| send morph（送信モーフ） | press, state change | Step 1: `width` to icon size with label fade, 250ms (use `clip-path` or fixed height to avoid layout thrash). Step 2: icon `translate` along a curve with WAAPI `cubic-bezier(.16,1,.3,1)` 500ms then `opacity: 0`. Reset on response. | Label changes to "Sent" with a 150ms fade; no flight. |
| 3D push（3Dプッシュ） | press | Face layer over a darker edge layer (`box-shadow: 0 6px 0 #…`); `:active { translate: 0 6px; box-shadow: 0 0 0 }` with a 100ms `ease-in-out` transition; works on touch via `:active`. | Same — no travel beyond a 2px shift, or colour only. |
| confetti burst（紙吹雪バースト） | state change | Spawn 20 to 40 spans at the button centre; WAAPI per piece: `translate` to a random radial target then gravity `translateY`, `rotate`, `opacity` to 0 over 900 to 1400ms; remove on `finish`. Or a canvas library. | Skip the burst; show a text or check confirmation. |
| hold to confirm（長押し確定） | press | `pointerdown` adds a class that runs `@keyframes` or transition on a fill layer `scaleX(0 to 1)` over 1000ms `linear`; `pointerup` cancels and reverses; `animationend` confirms. Add keyboard hold (Space) and `touch-action: manipulation`. | Show a plain two-step confirm (press, then press again); no fill. |
| border draw（ボーダードロー） | hover, focus, load | An SVG `rect` overlay with `pathLength="1"`, `stroke-dasharray: 1`, `stroke-dashoffset` 1 to 0 over 600ms `ease-out`; then a `scale` kick 1.03 to 1 on `cubic-bezier(.34,1.56,.64,1)`. | Border appears at once; no draw. |
| shine sweep（シャインスイープ） | hover, load | A `::after` with `linear-gradient(105deg, transparent, rgba(255,255,255,.5), transparent)`, `translate: -150% to 150%` over 700ms `ease-in-out`, parent `overflow: hidden`, one run per hover (touch: on tap). | Drop the band; keep a static highlight. |
| loading to success（読込から成功） | state change | Three steps on `data-state`: spinner `opacity` and `scale` out 150ms, check path `stroke-dashoffset` 1 to 0 over 300ms, then background and label swap. `aria-live="polite"` on the label. | Spinner swaps to a static check with a 100ms fade. |
| icon swap（アイコンスワップ） | press, state change | Two stacked icons; outgoing `rotate(90deg) scale(0)` and `opacity 0`, incoming starting `rotate(-90deg) scale(0)` to rest, 200ms `ease-in-out`; or Motion `AnimatePresence`. | Cross-fade in 100ms, no rotation. |
| heartbeat（ハートビート） | loop | `@keyframes` on `scale`: 0% 1, 14% 1.15, 28% 1, 42% 1.08, 70% 1; duration 1.4s `ease-out`; `animation-iteration-count: 4`. | Remove the loop; static state. |
| wobble tilt（ウォブルチルト） | hover, press | `@keyframes` `rotate` 0, -8deg, 6deg, -3deg, 1deg, 0 over 600ms `ease-out` around the centre; trigger on `:hover` inside `@media (hover: hover)`, and on tap. | No rotation; colour or outline change instead. |
| elastic drag（エラスティックドラッグ） | drag | `pointermove` sets `scale` and `skew` from the drag distance (clamped), `touch-action: none`; on release WAAPI back to identity 500ms with `linear()` spring or Motion `animate` spring (`stiffness 300, damping 12`). | Button moves without stretch and returns instantly. |
| inner press（インナープレス） | press | `transition: box-shadow 120ms ease-in-out, scale 120ms`; `:active { box-shadow: inset 0 3px 6px rgba(0,0,0,.4); scale: .98 }`. Inset shadow repaints but is small. | Same — no travel; shadow change only. |
| colour splash（カラースプラッシュ） | press | A circle at the pointer position scaled from 0 past the far corner (`scale` to the diagonal) over 500ms `ease-in-out`, clipped via `overflow: hidden`; label colour swaps late. | Instant fill colour. |
| breathing gradient（呼吸グラデーション） | loop | `background-size: 200% 100%` with `@keyframes` `background-position` 0% to 100% over 4s `ease-in-out`, `animation-iteration-count: 3`. Paints each frame, keep it small. | Static gradient. |
| button press（ボタンを押す） | press | `:active { scale: .96 }` 80ms, state class change, then a ripple span as in click ripple; clean and compact, no ringing. | `:active` colour change only; no scale or ripple. |
| one shape, never cut（1 つの形が変わり続ける） | state change | Motion `layout` with shared `layoutId`, or View Transitions with one `view-transition-name`; size, radius and colour move together on a spring; inner content cross-fades with a 6px `filter: blur`. | Instant state swaps, or a 150ms cross-fade; no resize travel. |

| bottom sheet drag（ボトムシート追従） | drag | Pointer drag on the handle sets `translateY`; backdrop `opacity` from the same progress; on release choose the nearest snap point and animate 300ms `cubic-bezier(.2,.8,.2,1)`; `overscroll-behavior: contain` inside. | Sheet jumps to the chosen stop; backdrop fades in 100ms. |
| pinch zoom（ピンチズーム） | drag | Track two pointers; scale = current distance / start distance; `transform-origin` at the midpoint (or compensate `translate`); `touch-action: none`; provide +/- buttons.
