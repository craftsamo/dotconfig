# Scroll-driven motion: web builds

How each entry of [../scroll.md](../scroll.md) is built on a real web page: the trigger that starts it (load, enter view, scroll progress, hover, focus, press, drag, state or route change), the smallest tool that builds it (CSS, then the Web Animations API, then a library) and what replaces it under `prefers-reduced-motion: reduce`. Read the entry's Looks like and The tell first. Typical values here come from common web practice; a project's own motion tokens win.

Scroll motion on a real page. Tell three kinds apart before building: once-on-enter (IntersectionObserver, or `animation-timeline: view()` with a short `animation-range` such as `entry 0% entry 40%`), scrubbed (`animation-timeline: scroll()` or `view()`, ScrollTrigger `scrub`) and pinned sequences (sticky wrapper plus a view timeline, or ScrollTrigger `pin`). Guard CSS timelines with `@supports (animation-timeline: view())` and fall back to an IntersectionObserver reveal or the static end state.

## Scroll-driven page

**Group 1: things that appear**

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| scroll-triggered fade-in / scroll reveal（フェードイン、スクロールリビール） | enter view | IntersectionObserver (`threshold: 0.2`) adds a class; CSS `transition: opacity 600ms, transform 600ms cubic-bezier(.22,1,.36,1)` from `opacity:0; translateY(24px)`. Or `animation-timeline: view(); animation-range: entry 0% entry 40%`. Unobserve after firing. | Opacity fade only, 150 ms, no translate; or show instantly. |
| slide-in（スライドイン） | enter view | IntersectionObserver toggles a class; `transform: translateX(-80px)` to `none` plus opacity, `transition: 700ms cubic-bezier(.16,1,.3,1)`; alternate sign by `:nth-child(even)`. Use `translate`, never `left`, to avoid layout. | Same — no travel: instant or a 150 ms opacity fade. |
| stagger（スタッガー） | enter view | One observer on the container; each child gets `transition-delay: calc(var(--i) * 70ms)` with `--i` set per index, same short rise and fade as the reveal. Cap total delay near 600 ms. GSAP: `stagger: 0.07`. | No stagger: all items appear at once, or one 150 ms fade. |
| text reveal / split text（テキストリビール） | enter view | Split into spans (keep the full text in a visually hidden copy, or `aria-label` only on a heading or an element with a role, and put `aria-hidden="true"` on the split spans); wrapper `overflow: hidden`, inner `translateY(100%)` to `0`, 800 ms `cubic-bezier(.16,1,.3,1)`, delay 60 ms per piece. Fire from IntersectionObserver. | Show text as is; optionally one 150 ms opacity fade. |
| clip-path reveal（マスクリビール） | enter view | `clip-path: inset(0 0 100% 0)` to `inset(0)`, 900 ms `cubic-bezier(.65,0,.35,1)`, class added by IntersectionObserver. Clip-path repaints but is compositable in modern engines; keep the image unscaled. | Show fully, or 150 ms opacity fade; no wipe. |
| blur-in reveal（ブラーイン） | enter view | `filter: blur(12px)` to `blur(0)` with opacity and `translateY(16px)`, 700 ms ease-out; make the blur transition 100 ms shorter. Paint-heavy: limit to a few elements and drop `will-change` after. | Opacity fade only; no blur or travel. |
| typewriter（タイプライター） | enter view | Pure CSS: `width: 0` to `Nch` with `steps(N)` on `monospace`, `overflow: hidden; white-space: nowrap`, `border-right` caret with a blink keyframe. Variable text: JS `setInterval` of ~40 ms with small jitter, starting from IntersectionObserver. | Print the full text at once; caret static or none. |
| count-up（カウントアップ） | enter view | IntersectionObserver starts a `requestAnimationFrame` loop of ~1200 ms with ease-out (`1 - (1 - t) ** 3`); write `Math.round` into the text with `font-variant-numeric: tabular-nums`. Keep the final value in markup. | Show the final number immediately. |

**Group 2: motion tied to scroll progress**

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| scroll-linked animation（スクロール連動） | scroll progress | `animation: name linear both; animation-timeline: view(); animation-range: entry 0% cover 50%` on any transform, opacity or filter keyframes. Easing stays `linear`. Fallback: GSAP ScrollTrigger `scrub: true`. | Remove the timeline; show the end state statically. |
| parallax（パララックス） | scroll progress | `animation-timeline: scroll()` or `view()` on each layer with `translateY` from `-10%` to `10%` for the backdrop and larger for the foreground, `linear`. Or ScrollTrigger `scrub` with `y` per layer. Translate only. | Remove parallax entirely; layers stay in place. |
| scale on scroll / scroll depth zoom（スクロールズーム、スクロール奥行きズーム） | scroll progress | Sticky stage plus `animation-timeline: view(); animation-range: contain`, `scale: 0.8` to `1` with `filter: brightness(.6)` to `1`, `transform-origin: center`, `linear`. Scale a wrapper, not width. | Remove zoom; show final size and brightness. |
| scroll-scrubbed image sequence（画像シーケンス） | scroll progress | Preload frames; draw to a `<canvas>` with `drawImage` at `index = Math.round(progress * (n-1))` from a ScrollTrigger `onUpdate` (pinned) or a scroll listener with `requestAnimationFrame`. Mind memory: use small, compressed frames. | Show one representative still frame; no scrub. |
| SVG line drawing（SVGラインドロー） | scroll progress | `pathLength="1"` on the path; `stroke-dasharray: 1; stroke-dashoffset: 1` to `0` via `animation-timeline: view()`, `linear`. Or ScrollTrigger `scrub` on `strokeDashoffset`. | Show the full path statically. |
| text fill on scroll（テキストフィル） | scroll progress | Words in spans; each with `animation: fill linear both; animation-timeline: view(); animation-range: entry calc(var(--i) * 3%) entry calc(var(--i) * 3% + 20%)`, opacity `.25` to `1`. Fallback: IntersectionObserver per word. | Show all words at full colour. |
| background colour transition（背景色トランジション） | scroll progress | A fixed full-frame layer with `animation: bg linear both; animation-timeline: scroll()` keyframes between colours; or ScrollTrigger `scrub` on `backgroundColor`. Colour paint only, no layout. | Swap to the target colour instantly at the section boundary, or a short fade. |
| marquee / scroll velocity / scroll marquee（マーキー、スクロールマルキー） | loop, scroll progress | Doubled strip with `animation: marquee 30s linear infinite` (`translateX(0)` to `-50%`); add a pause button (or pause on hover and focus) because it runs past five seconds. Velocity: JS reads scroll delta each frame and calls `updatePlaybackRate()` on the Animation from `el.getAnimations()` (WAAPI) or uses Motion's `useVelocity`. Or a rAF loop: `x = (x + base + velocity * k) % copyWidth` with `translate3d`, velocity smoothed by a spring (Motion `useSpring`) or `lerp 0.08`, direction from sign, the second band mirrored with `-1`. | Stop the loop; show a static, wrapped row. |
| scroll progress（スクロール進捗） | scroll progress | `position: fixed; top: 0; height: 3px; transform-origin: left; animation: grow linear both; animation-timeline: scroll(root)` with `scaleX(0)` to `scaleX(1)`. Fallback: scroll listener setting a CSS variable. | Same — no travel (a bar update is not decorative motion). |
| text scroll resolve（文字スクロール解像） | scroll progress | Per-character spans with `--i`; keyframes from offset `translate`, small `rotate`, `blur(6px)` to none; `animation-timeline: view()` with `animation-range` shifted by index; scatter from a fixed seed (CSS variables). Keep readable text for screen readers. | Show the headline sharp and in place. |
| image clip scrub（画像クリップスクラブ） | scroll progress | `clip-path: inset(30% round 24px)` to `inset(0 round 0)` via `animation-timeline: view(); animation-range: entry 0% cover 40%`, `ease-in-out` or linear; image in a sticky wrapper. Or ScrollTrigger `scrub`. | Show the full-frame image without clipping. |
| scroll velocity skew（スクロール速度スキュー） | scroll progress | JS: Lenis `velocity` or `(scrollY - last)` per frame, `skewY = clamp(velocity * 0.1, -6, 6)deg` via CSS variable, eased back with `lerp` 0.1 or a 200 ms transition; for a swing slightly past upright feed the velocity to a spring (Motion `useSpring`, stiffness ~300, damping ~20, clamp about 8 deg). Transform only. | Remove skew entirely. |

**Group 3: fixed, paged and navigation**

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| sticky / sticky pin（スティッキー、スティッキーピン） | scroll progress | `position: sticky; top: 0` inside a tall parent (the span of the hold equals the parent's height minus the element). No JS; avoid `overflow: hidden` on ancestors, which breaks sticky. | Same — no travel (sticky is layout, not motion). |
| pin + scrub（ピン留め＋スクラブ） | scroll progress | Sticky wrapper in a tall track; inner keyframes on `animation-timeline: view()` of the track (`animation-range: contain`), `linear`. Or ScrollTrigger `pin: true, scrub: true, end: "+=1500"` on a GSAP timeline. | Unpin: stack the end state in normal flow without scrubbing. |
| scrollytelling / pinned story steps（スクロールテリング、ピン留めストーリー） | scroll progress, enter view | Sticky visual column, text steps in the flow; one IntersectionObserver (`rootMargin: "-50% 0px"`) sets `data-step` and CSS transitions swap the visual (`500 ms ease-in-out`). Or ScrollTrigger per step. | Swap steps instantly or with a 150 ms fade; no pin-scrub tweening. |
| stacking cards（カードスタック） | scroll progress | Each card `position: sticky; top: calc(2rem + var(--i) * 1rem)`; previous card `animation-timeline: view()` with `scale` `1` to `.92` and `filter: brightness(.8)`. Or ScrollTrigger `pin` per card. | Render a plain vertical list without scale or dim. |
| scroll snap（スクロールスナップ、セクションスナップ） | scroll progress | `scroll-snap-type: y mandatory` on the scroller, `scroll-snap-align: start` on sections; prefer `proximity` for long content. GSAP: ScrollTrigger `snap: 1/(n-1)`. Test keyboard and touch. | Keep snap (it is native) but set `scroll-behavior: auto`; no animated jumps. |
| horizontal scroll / horizontal scrub（横スクロール、横スクロールスクラブ） | scroll progress | Tall section with sticky child; inner row `translateX(0)` to `calc(-100% + 100vw)` via `animation-timeline: view(); animation-range: contain` on the section, `linear`. Or ScrollTrigger `pin`, `scrub`, `x: () => -(row.scrollWidth - innerWidth)`. | Use native `overflow-x: auto` with scroll-snap instead of scroll-jacking. |
| hide-on-scroll header（隠れるヘッダー） | scroll progress | Passive scroll listener (`{ passive: true }`) records `scrollY` and reads it in `requestAnimationFrame`, comparing with the last value (ignore under 8 px); toggle `data-hidden`; CSS `transform: translateY(-100%)` with `transition: transform 250ms cubic-bezier(.2,.8,.2,1)`. Keep it shown on focus (`:focus-within`). | Toggle visibility instantly, no slide. |
| scrollspy（スクロールスパイ） | scroll progress, state change | IntersectionObserver on sections (`rootMargin: "-40% 0px -55% 0px"`) sets `aria-current` on the matching link; indicator moves via `transform: translateY()` with `transition: 250ms ease-out`. | Move the indicator instantly; the highlight stays. |

## Scrolling text

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| scrubbed chapter index（章番号スクラブ） | scroll progress | IntersectionObserver per section sets the numeral text; the change plays a 250 ms slide-and-fade (`translateY(8px)` to `0`, opacity `0` to `1`) via WAAPI. Or a stacked column of numerals translated by `scroll()` timeline in steps. | Swap the number instantly. |
| scroll word highlight（スクロールで単語明転） | scroll progress | Words in spans; per-word `animation-timeline: view()` with overlapping `animation-range` slices, opacity `.2` to `1`, `linear`. Or ScrollTrigger `scrub` on a stagger timeline. | Show all words at full opacity. |
| view-timeline word reveal（CSS view() 単語リビール） | scroll progress, enter view | Native: `animation: rise linear both; animation-timeline: view(); animation-range: entry calc(var(--i) * 4%) entry calc(30% + var(--i) * 4%)` with `translateY(1em)` and opacity. Fallback under `@supports not`: IntersectionObserver with delays. | Show the line at once, no drift. |
| scroll reveal blur and tilt（傾き+ブラー解像） | scroll progress | Block: `rotate: 3deg` to `0` via `animation-timeline: view()`; words: `filter: blur(4px)` and opacity to clear, ranges offset per `--i`, `linear`. Limit blur to short copy for paint cost. | Show upright, sharp, full opacity. |
| scroll clip write-on（スクロール書き出し） | scroll progress | `clip-path: inset(0 100% 0 0)` to `inset(0)` via `animation-timeline: view()` with `animation-range` per line (offset by line index), `linear`. Split by line spans for line-wise writing. | Show the text unclipped. |
| horizontal scroll letter drop（横スクロール文字落下） | scroll progress | Pinned container (ScrollTrigger `pin`, `scrub`) with title `x` linear; per-letter `y: -200, scale: 1.6` to rest with `ease: "back.out(1.7)"`, stagger 0.05; parent `overflow: hidden`. | Static title, letters at rest, no pin. |
| dual wave columns（デュアルウェーブ列） | scroll progress | Per-item `translateX` = `sin(y * f + phase) * amp` computed from scroll progress in rAF or ScrollTrigger `onUpdate`; negate the second column; emphasise the centre by `scale` and colour. Write via CSS variables. | Align the columns straight; keep the emphasis by colour only. |
| text repetition echo（テキスト反復エコー） | scroll progress | Stacked absolutely-positioned copies (`aria-hidden`), `transform-origin: 50% 100%`, `rotate(calc(var(--i) * 6deg))` and opacity falling with `--i`, driven by `animation-timeline: view()`, ease-in-out. | Show the single word only; hide the copies. |
| sticky shrinking headline（追従縮小見出し） | scroll progress | `position: sticky; top: 0` headline; `transform-origin: top left`, `scale: 1` to `.12` via `animation-timeline: scroll()` over the first 60 vh, `linear`; never animate `font-size`. | Place the headline in its small header state with no scaling. |
| line parallax（行ごとのパララックス） | scroll progress | Per-line span with `animation: drift linear both; animation-timeline: view()` and `--speed` multiplying a `translateY(calc(var(--speed) * 40px))` end value; the section `overflow: clip`. | Lines stay in place at midpoint spacing. |
