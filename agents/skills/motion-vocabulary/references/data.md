# Paths, diagrams and data vocabulary

A dictionary, not a rulebook. It extends [core.md](core.md) with names for drawn paths, strokes, charts, maps and the moments that turn numbers into a story. Each entry gives its Feel (one or two of the five words defined in [timing.md](timing.md) "## Feel"), For (what it is usually applied to), Looks like and The tell (the detail that makes it read as itself and how it differs from a near neighbour). How each entry is built in a rendered video is in [video/data.md](video/data.md).

## SVG and paths

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| svg stroke draw（SVG線描画） | smooth | logo, UI | an outline draws itself, as if a pen were tracing it in one pass | the stroke head advances in path order and leaves the complete outline behind it; the line is hidden ahead of the head — vs `signature stroke`: one path at one pace, not strokes joined in a writing order |
| svg path morph（SVGパスモーフ） | smooth | UI | one outline turns smoothly into another, like clay being reshaped | contour points slide to nearby counterparts without crossing over each other, so the in-between shapes stay clean rather than tangled — vs `liquid morph`: crisp contours throughout, not a blobby merge |
| svg segment trim（区間トリム） | snappy | logo, UI | a visible piece of a path slides along it, like a bead of light running a track | a fixed-length piece travels while its tail disappears at the same rate as its head advances, so the length stays constant — vs `border chase`: any path, with ends that trim, not a lap around a box |
| svg motion path（モーションパス追従） | smooth | UI, character | an item travels along a path and turns with it, like a car on a track | the item's centre stays exactly on the path and its rotation follows the local direction of the curve, so it banks through bends — vs `path follow`: the route itself is an SVG path with its own geometry |
| svg mask reveal（SVGマスクリビール） | soft | logo, text | a shape grows as a mask and uncovers the artwork underneath, like a spotlight opening | the content stays still and only the mask boundary grows, past full size by the end so no part of the art stays hidden — vs `iris / circle reveal`: the mask can take any drawn shape, not only a circle |
| svg gradient flow（グラデーション流動） | smooth | logo, 3D | colour seems to flow along a line, like liquid moving through a pipe | the stroke itself stays fixed and only a bright band travels along it at an even pace, in one direction — vs `marching dashes`: the colour band travels along a fixed line, no dashes move |
| gooey merge（グーイーマージ） | soft | logo, 3D | blobs that touch fuse and part like liquid drops | a narrow bridge forms when two blobs get close, then merges into one contour and later pulls apart into a thread before it breaks |
| signature stroke（署名ストローク） | smooth | logo, text | handwriting is written in one pass, as if signed with a pen | each stroke flows into the start of the next, in the order a hand would write, with rounded ends — vs `svg stroke draw`: several strokes chained in writing order |
| radial repeater（リピーター） | smooth | logo, UI | one shape is copied around a centre like petals, forming a flower or wheel | the copies rotate and offset in time, so the pattern keeps shifting like a kaleidoscope while the centre stays still |
| noise blob（ゆらぐブロブ） | soft/smooth | UI, logo | a blob whose edge wobbles slowly, like a drop of oil | the outline swells and shrinks at different rates in different places, so it reads as an organic form rather than a plain circle being scaled — vs `breathing scale`: the shape of the edge changes, not just the size |
| radiating burst lines（集中線、放射の線） | snappy/bouncy | UI, logo, character | straight lines fan out from a point, like a comic burst of emphasis | the lines extend one after another and then vanish from their base end, so the burst looks thrown outward and gone |
| marching dashes（破線が流れる） | smooth | UI | a dashed line whose dashes crawl along it in a file, like a column of ants following a trail | the pattern flows in one direction at an even pace, every dash keeping its shape and spacing, while the line itself does not move or grow — vs `border chase`: that is one bright runner on a dim border, here every dash travels and the whole line is lit |

## Data storytelling

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| sankey flow reveal（サンキー流量リビール） | smooth | UI | flowing bands fill from source nodes to target nodes, their thickness showing the amounts, like pipes filling with coloured water | the bands run in order from the source side to the target side and their width carries the value, so thick flows read as large at once; the fill front travels with the flow direction |
| metric odometer cascade（指標オドメーター） | smooth | UI | several metrics roll their digits like odometers, one metric after another, each ending on its figure | each metric rolls in turn and settles on its final digit, the units digit turning fastest and the leading digits slowest, so the last figure locks in a beat apart from the next |
| threshold alarm wave（閾値アラーム波） | smooth | UI | a line crosses a limit and the alert colour spreads out from the crossing, like a stain | the colour starts exactly at the crossing point and travels outward from there along the chart, while the rest of the chart keeps its calm palette until the wave reaches it |
| forecast confidence fog（予測信頼度フォグ） | heavy | UI | the future part of a line sits inside a haze that widens with distance, like fog thickening ahead | the haze starts almost thin at the present point and grows wider and softer the further into the future it goes, so uncertainty reads as spatial |
| live signal pulse map（ライブ信号パルスマップ） | smooth | UI | dots on a map send out pulse rings as events occur, like sonar pings | pulses start at different points at different moments, and a ring fades as it grows so that several can overlap without clutter |
| comparison delta split（比較デルタ分割） | smooth | UI | two values start together, then separate and the gap between them is bracketed and labelled | the gap opens from a shared baseline, then a bracket closes around it and the difference number appears just after the move ends, so the number follows the visual |
| timeline scrub trail（タイムライン軌跡） | smooth | UI | a playhead moves along a timeline and leaves a trace of earlier values behind it | the dot at the front is the brightest, while earlier parts of the line fade behind it, so the eye tracks the present moment |
| network topology bloom（ネットワークトポロジー展開） | bouncy | UI | a network grows from one node outward, like a root system spreading | nodes pop in order of their depth from the first one, and each edge is drawn out toward its node just before it appears |
| progress milestone firefly（進捗マイルストーン蛍） | smooth | UI | a glowing dot travels along a track and lights each milestone as it passes, like a firefly on a trail | each milestone glows at the moment the dot reaches it and remains lit, while those ahead stay dim |
| heatmap ripple focus（ヒートマップ注目波） | bouncy | UI | the hottest cell pulses and a ripple spreads across its neighbours, like a drop on a grid | neighbours react less the farther they are from the centre, so the response fades with distance from the cell |
| stream graph breathing（ストリームグラフ呼吸） | smooth | UI | layered bands swell and thin in a slow loop, like a stream graph breathing | each band changes thickness at its own pace while the stack as a whole holds a steady outline, so the layers seem to exchange volume |
| rank ladder climb（順位ラダー上昇） | snappy | UI | an item climbs the ranking and the others shift down to make room | one item jumps up several places while the others step down by one place each, so the swap reads as a climb |
| data cluster merge（データクラスタ結合） | bouncy | UI | groups of points pull together into one cluster, like filings drawn to a magnet | the points overshoot the centre slightly and fall back, so the cluster briefly looks tighter than its final size |
| event sequence domino（イベント列ドミノ） | heavy | UI | events on a line fall one into the next, like dominoes | each item tips against the next so the sequence seems to carry a push along the line, its force building with the chain |
| kpi spotlight relay（KPIスポットライトリレー） | smooth | UI | a spotlight passes from one key figure to the next, like a baton | the previous figure dims at the same time as the next one lights, so the attention is handed over rather than switching off between them — vs `spotlight focus`: a handover between several targets, not a single one |
| radial budget bloom（放射予算ブルーム） | smooth | UI | ring slices open out around a centre, sized by their share of the budget | the slices grow one after another round the ring and their labels count up in step with the arc length |
| calendar density sweep（カレンダー密度スイープ） | snappy | UI | a sweep colours calendar cells by how busy each day is, like a heat tint passing over the month | the cells fill in order across the rows, and the busiest days end up in the deepest colour while the quiet days stay pale |
| live queue compression（ライブキュー圧縮） | bouncy | UI | items line up into a queue that squeezes as the line advances | each arrival squashes slightly against the one in front and the rest shift forward by a step |
| sentiment spectrum shift（感情スペクトラム遷移） | smooth | UI | a marker slides along a colour spectrum as the mood changes, like a needle on a gauge | the gradient bar stays fixed while only the marker moves, and the label swaps while it passes the midpoint |
| goal projection arc（目標予測アーク） | smooth | UI | a dashed arc stretches from today's point toward a faraway goal, like a flight route being drawn on a map | the dashes extend steadily from the start with the head leading, and the goal marker stays hidden until the arc lands, then pops once at the end — vs `svg stroke draw`: that traces a solid outline, this one is dashed, aims at a target and finishes with a marker |
| scatter reveal（散布図が現れる） | smooth | UI | dots appear across the axes, and a trend line is then drawn through them | the points come first in a loose scatter and only then does the line draw, so the pattern is revealed after the evidence |
