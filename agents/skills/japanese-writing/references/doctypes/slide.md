# スライド構成案

## この文書が答える問い

スライド構成案は「各スライドのメッセージライン（主張の1文）だけを1枚目から順に読んで、結論までの論理が通るか」に答えます。聞き手が1枚のスライドを眺める時間は数秒に限られるため、地の文の説明に頼らずメッセージラインと最小限の根拠で伝わる設計にします。

## 各スライドの3層構造と全体構成

各スライドは以下の3要素で組み立てます。

- タイトル: そのスライドが扱う対象（短いラベル名詞句でよい）
- **メッセージライン**: そのスライドで最も伝えたい結論を述べた1文（「導入の効果」のようなラベルで終わらせず、「測定機器の更新により外注検査38件を内製化できる」のように結論を書く）
- 根拠: メッセージラインを支える実数・比較表・具体例（メッセージラインの言い換えや一般論を並べない）

全体は「表紙 → 導入（課題と求める判断） → 本論（主要な根拠グループを2〜3束に絞る） → 結び（誰にいつまでに何を決めてほしいか）」が基本構成です。枚数を先に決めて中身を水増しせず、重要な枚は根拠を厚く、補足的な枚は1〜2点で軽く流します。手元にない数値を仮の数字や `[金額]` の穴埋めのまま完成稿として出さず、未確認事項として末尾に明記します。

## 短い例（メッセージラインの骨格確認）

Before（見出しラベルの羅列で主張が見えない）:

```text
1. 研究室の概要
2. 現状の課題
3. 予算の内訳
4. 期待される効果
5. まとめ
```

After（メッセージラインだけで結論まで追える）:

```text
1. 分光測定器を更新すれば、来年度の共同研究2件を予定どおり開始できる
2. 現行機は導入から14年が経過し、今年度は4回の故障で計23日間停止した
3. 申請額620万円の6割を本体更新、残りを保守契約と消耗品に充てる
4. 更新後は外部委託している測定（年38件）を学内実施へ切り替えられる【要確認: 年間削減額】
5. 12月の配分委員会にて更新予算620万円の承認をお願いしたい
```
