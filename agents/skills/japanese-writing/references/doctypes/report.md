# 調査・分析レポートと業務報告書

## この文書が答える問い

調査・分析レポートや各種報告書（障害報告、監査報告、月次報告など）は、「何が分かったか」「それはどの程度確かか」「その結果どう行動すべきか」に答えます。数値を並べるだけで終わらせず、数値が判断にどう関わるかを示します。

## 必須要素と構成

1. 冒頭の要約: 主要な結論と核となる数値を冒頭数行にまとめます。多くの読み手は要約で全体像を掴み、必要な箇所だけ本文を参照します。続報の場合は前回調査からの変化点（訂正があればその旨も）を冒頭近くに明記します。
2. 対象範囲・定義・方法: 調査期間、母集団、件数、除外条件、指標の定義、データの取得方法を最初の数値より前に置きます。小規模な実施報告では1〜2文で簡潔に述べます。
3. 結果（事実）と考察（解釈）の分離: 観測された事実と書き手の解釈を文末や主語で明確に区別します（例: 「412便中37便で基準温度を超過した」と「荷下ろし回数の多さが要因と推定される」を混ぜない）。
4. 数値の文脈と限界: 「回答率 15%（200人中30人）」のように割合と実数を併記します。外れ値の影響やサンプル数の少なさなどの制約は、末尾にまとめず**該当数値の直後**に注記します。
5. 次の行動: 調査結果が裏付ける範囲内で、誰が何を検証・実施するかを示します（短期の相関だけから因果を断定した過大な提言はしない）。

障害・事故報告では「発生事象と影響 → タイムライン（表が有効） → 原因（確定事項と推定の分離） → 暫定対処 → 恒久対策」の順が基本です。変化のあった重要項目を厚く書き、異常のない定常項目は1行で簡潔に済ませます。

## 短い例

Before（数値の羅列と抽象的な締めで終わっている）:

> 9月の配送412便のうち、荷室温度が基準を超えた便は37便だった。超過時間の平均は18分だった。店舗別では北部の店舗が多かった。今後も温度管理の徹底が重要である。

After（母数・外れ値の注記・推定と検証アクションを明示）:

> 9月に冷蔵生地を配送した412便のうち37便（約9%）で、荷室温度が基準の10℃を超過しました（車載温度記録計、9月1日〜30日）。超過した37便のうち29便は北部4店舗向けで、いずれも1便で3か所以上に荷下ろしするルートでした。超過時間の平均は18分ですが、車両トラブルによる約4時間半の1便が含まれており、これを除いた平均は11分です。
>
> 荷下ろし回数が温度上昇の主因かは1か月分の記録だけでは推定にとどまります。10月は北部ルートを2便に分割して1便あたりの荷下ろしを2か所以下とし、同じ記録計で超過便数が減少するか検証します。
