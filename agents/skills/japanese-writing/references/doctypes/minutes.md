# 議事録（文字起こしからの作成を含む）

## この文書が答える問い

議事録は「何が決まったか」「誰がいつまでに何をするか」「何が次回以降の宿題・持ち越しになったか」に答えます。欠席者や後から見返す関係者が、全文を読まなくても決定事項とタスクを即座に把握できる構成にします。

## 必須要素と構成

1. 会議情報と記録の前提（冒頭）: 会議名、日時、出席者、記録者に加え、記録の元データ（文字起こし・録音・メモ）と話者特定の確度を数行で添えます。
2. 決定事項・TODO・持ち越し事項の独立配置: 議論の途中に埋め込まず、冒頭直後（または末尾の固定位置）に独立セクションとして箇条書きでまとめます。
   - 決定事項: 何がどう決まったかを具体的に書きます（「引き続き検討する」は決定ではないため持ち越し事項へ分類します）。
   - TODO（宿題）: **担当者・期限・具体的なアクション**の3点を揃えます。会議中に担当や期限が決まらなかった場合は推測で埋めず「担当未定（次回決定）」と明記します（原文にない空欄列を形式のためだけに増やしません）。
   - 持ち越し事項: 次回いつ・何を判断するかを残します。
3. 議題別の議論要旨: 発言を時系列になぞるのではなく、決定や持ち越しに至った理由・懸念・対案の経緯を地の文で簡潔にまとめます。5分の確認事項は1行で済ませ、議論が割れた重要議題を厚く書きます。

## 文字起こしから起こすときの注意

- 話し言葉の冗長な言い回しは要点に整理しますが、**発言者の確信度や留保（「おそらく2週間で足りる」「電源が足りないかもしれない」）を勝手に断定へ書き換えないでください**。
- 重要な発言をかぎ括弧（「発言内容」）に入れて引用する場合は口調を改変せずそのまま残し、要約はかぎ括弧の外で書きます。
- 話者が確実に特定できない箇所は断定せず「（話者推定）」と注記します。文体は会議体の既存慣習（「である」調・体言止め・敬体のいずれか）に揃えます。

## 短い例

```markdown
# 中央図書館改修検討委員会 第4回（2026年9月18日）

出席: 大西（館長）、森（利用者代表）、川口（市施設課） / 記録: 秋山（録音文字起こしより作成、名乗りのない発言は話者推定）

## 決定事項
- 工事期間中（2027年1月〜4月）、2階会議室を仮設の学習室として開放する

## TODO
- 川口: 2階会議室への机・電源増設費用を見積もる（10月2日まで）
- 秋山: 利用者アンケート結果をもとに仮設学習室の開館時間案を作成する（10月9日まで）

## 持ち越し事項
- 増設費用の財源（改修予算に含めるか別枠か）— 次回、見積もりを確認して決定する

## 議論要旨: 工事中の学習席確保
1階学習室（48席）が4か月間閉鎖されることに対し、森から「受験期と重なるため学習席ゼロは避けてほしい」と要望があった。川口は2階会議室に30席程度は配置可能としつつ、「電源容量は不足するかもしれない」と留保した。大西が2階会議室の仮設開放を提案し、異議なく合意した。
```
