# 文体プロファイル

> 利用者から明示的に作成を依頼されたときだけ、本人の過去の文章（3〜5本程度）を根拠に作成します。標本数が限られるため断定せず「傾向」として記述し、根拠のない項目は推測で埋めず空欄にします。「避ける表現」は本人が特定の文脈で違和感を示した狭い記録として扱い、他の書き手や無関係な文書へ一般化しません。

## 参照した文章

- 題名:
  - 種別（技術記事、Issue/PR、報告書、メール、エッセイなど）:
  - 執筆時期・想定読者:
  - 参照元（URL またはパス）:

## 視点と態度

- 一人称（私、僕、自分、筆者、使わない等）:
- 読者への語りかけ方:
- 言い切りと留保のバランス（どの程度断定するか、留保に使う表現）:

## 文体とリズム

- 基本の文末（敬体「です・ます」、常体「だ・である」、文書種別ごとの使い分け）:
- 特徴的な文末表現（体言止めの頻度、「〜と考えています」など）:
- 一文・一段落の長さの傾向と長短の混ぜ方:
- 読点の打ち方や改行・空行の癖:

## 語彙と表記

- よく使う語句・言い回し:
- 専門用語・カタカナ語・漢語熟語の扱い（そのまま使う、初出のみ補足するなど）:
- 固有名詞・数値・具体例の入れ方:
- 漢字とかなの使い分け、括弧（全角/半角）やスペースの好み:

## 避ける表現

- 表現（単語単体ではなく、問題になった文脈と組み合わせ）:
  - 避ける文脈:
  - 代替表現の候補:
  - 使ってよい例外:
  - 根拠（本人の指摘・修正履歴など）:

## 構成の傾向と備考

- 導入の入り方（結論先行、背景・課題から、具体的な出来事から等）:
- 見出しの付け方、箇条書き・表の使い方、結び方:
- 文書種別による変化（例: Issue や報告では簡潔な言い切り、エッセイでは余韻を残す等）:
