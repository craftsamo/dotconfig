# 文体プロファイル

> ユーザーが明示的に依頼したときだけ本人の過去の文章 3〜5 本から作り、標本が少ないため各項目は断定せず「傾向」として書きます。
> 「避ける表現」は本人が違和感を示した文脈にだけ適用する狭い規則であり、一般的な禁止語として他の文脈や他の書き手へ広げません。
> 各項目には根拠になった文章と箇所を残し、根拠のない項目は推測で埋めずに空欄にします。
