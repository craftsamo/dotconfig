# Core motion: web builds

How the text animations and transitions of [../core.md](../core.md) are built on a real web page (the core's other sections have no page form): the trigger that starts it (load, enter view, scroll progress, hover, focus, press, drag, state or route change), the smallest tool that builds it (CSS, then the Web Animations API, then a library) and what replaces it under `prefers-reduced-motion: reduce`. Read the entry's Looks like and The tell first. Typical values here come from common web practice; a project's own motion tokens win.

## Transitions (between beats)

Set the default once: `@view-transition { navigation: auto; }` in every page for same-origin navigations, or call `document.startViewTransition(update)` for in-page state; guard with `if (!document.startViewTransition) { update(); return; }`. Style `::view-transition-old(root)` and `::view-transition-new(root)`; use view-transition types or the `pageswap`/`pagereveal` events to choose direction.

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| crossfade / dissolve（クロスフェード、ディゾルブ） | route change | The View Transition default: `::view-transition-old(root), ::view-transition-new(root) { animation-duration: 350ms; animation-timing-function: linear; }`. Fallback: stack two layers with `opacity` transition 350ms. | same — no travel |
| blur crossfade（ブラー・クロスフェード） | route change | `::view-transition-old(root) { animation: fade-blur-out 400ms ease-in-out both; }` with keyframes to `filter: blur(12px); opacity: 0`, and the new one from blurred. Filter repaints; keep to the main region. | Opacity fade only, no blur. |
| push / slide（プッシュ、押し出し） | route change | Both pseudo-elements `translateX`: old `0` to `-100%`, new `100%` to `0`, same 400ms `cubic-bezier(.65,0,.35,1)`; flip direction by a class or view-transition type. Fallback: instant swap. | Instant swap or 150ms fade. |
| carrier handoff（キャリーハンドオフ） | route change | Give the moving object `view-transition-name: carrier` on both sides so the group interpolates position; or keep it in a persistent `position: fixed` layer outside the swapped container, animating `transform` across. | Object placed at its end position at once. |
| zoom-through（ズームスルー、scale-through） | route change | Old `scale: 1 to 1.6; filter: blur(8px); opacity: 0` ease-in; new `scale: .8 to 1; opacity: 0 to 1` ease-out, 500ms total, via `::view-transition-old(root)` and `new(root)`. | Crossfade only. |
| inverse zoom / arrival（逆ズーム、アライバル） | route change | `::view-transition-new(root)` keyframes `scale(1.25)` to `1` with `cubic-bezier(.34,1.3,.64,1)`, 500ms; old `scale: .9; opacity: 0`. | Fade in at the final size. |
| dolly into screen（画面へ飛び込む） | press | Device wrapper `transform: scale(1 to N)` with `transform-origin` at the screen centre, N so the screen matches the viewport; 900ms `cubic-bezier(.65,0,.35,1)`; then swap to the live page. | Cut to the screen content with a fade. |
| pull-back reveal（引きで見せる） | load | Wrapper starts `scale: 4` with `transform-origin` at the detail, animates to `1` over 1.2s `cubic-bezier(.16,1,.3,1)`; or scroll-driven `animation-timeline: view()`. | Show the whole scene directly. |
| clip-path wipe（クリップパスワイプ、ワイプ、linear wipe、インセット・クリップ、inset、マスクワイプ） | route change | `::view-transition-new(root) { animation: wipe 500ms cubic-bezier(.65,0,.35,1); }` with `@keyframes wipe { from { clip-path: inset(0 100% 0 0); } to { clip-path: inset(0); } }`; set `::view-transition-old(root) { animation: none; }`. Fallback: `clip-path` transition on an overlay. | Instant swap. |
| clock wipe（クロックワイプ） | route change | Mask `conic-gradient(#000 var(--a), transparent 0)` on the new layer with `@property --a { syntax: '<angle>'; inherits: false; initial-value: 0deg; }` animating `--a` 0deg to 360deg in 800ms `ease-in-out`. | Instant swap or 150ms fade. |
| iris / circle reveal（アイリス、丸く開く、アイリスオープン、アイリス円形リビール） | press | `clip-path: circle(0 at X Y)` to `circle(150% at X Y)` on `::view-transition-new(root)` via `animate(..., {pseudoElement})` after `.ready`, 500ms `cubic-bezier(.65,0,.35,1)`; old and new animation `none`. | Instant swap. |
| shaped iris（形のアイリス、ハート、鍵穴） | press | `mask-image: url(shape.svg)` with `mask-size: 0` to `300%` and `mask-position` at the point, `mask-repeat: no-repeat`, 700ms ease-in, on the incoming layer; fallback `clip-path: path()` (not scalable). | Instant swap. |
| colour flood（カラーフラッド） | route change | Fixed overlay in the brand colour, `clip-path: circle(0 at X Y)` to `circle(150%)` over 350ms ease-in, run the swap when covered, then clip away over 350ms ease-out. | Instant swap; no flash. |
| slats / blinds（スラット、ブラインド） | route change | 8-12 bar divs over the new view, each `transform: scaleY(1 to 0)` with `transform-origin: top`, 400ms ease-out, `animation-delay: calc(var(--i) * 40ms)`; remove after. | Instant swap. |
| staggered blocks（ブロックで覆う） | route change | Grid of divs `scale: 0 to 1`, `animation-delay: calc((var(--x) + var(--y)) * 30ms)`, swap at full cover, then reverse; keep under 100 tiles. | Instant swap. |
| light wipe（ライトワイプ） | route change | Overlay `linear-gradient(90deg, transparent, #fff8, transparent)` translated `-100%` to `100%` in 600ms ease-in-out; swap while it crosses the middle; new view `clip-path` follows its trailing edge. | Instant swap. |
| glow wash（グローウォッシュ） | route change | Fixed overlay with `radial-gradient(#fff, #fff0)`, `opacity: 0 to .95 to 0` over 600ms ease-in-out, swap at the peak. | Short opacity fade without a white flash. |
| card flip（カードフリップ、3Dフリップ、3D card flip） | press | Two faces in a `perspective: 1000px` wrapper with `transform-style: preserve-3d`; `rotateY(180deg)` on the wrapper over 600ms `cubic-bezier(.65,0,.35,1)`; `backface-visibility: hidden` on both faces. | Faces swap with a fade. |
| fold / unfold（折りたたみ） | press | Two halves, top with `transform-origin: bottom` and `rotateX(0 to -90deg)` in a `perspective` parent, shade overlay `opacity`, 500ms ease-in-out; swap content half way. | Instant swap. |
| shutter slices（シャッタースライス） | route change | N strips each showing a slice via `clip-path: inset()`; alternate `translateY(±100%)` with 30ms stagger over 450ms ease-in, new view underneath. | Instant swap. |
| push stack（プッシュスタック） | route change | `::view-transition-new(root)` `translateY(100%)` to `0`; old `scale: .94; filter: brightness(.7)` kept in place, 450ms `cubic-bezier(.65,0,.35,1)`, new on top via `z-index`. | Crossfade only. |
| split-screen expand（分割拡大） | press | Two panes in a flex row, `flex-grow` transition 500ms `cubic-bezier(.65,0,.35,1)` (layout cost; prefer `clip-path: inset()` on the winning pane); hide the other at the end. | Selected pane shown at once. |
| dither / pixel dissolve（ピクセルディゾルブ） | route change | Canvas overlay of cells flipping from the old snapshot to the new in seeded random order over 500ms, or a pixel-pattern `mask-image` with `steps()` timing; fallback crossfade. | Plain crossfade. |
| shape-morph bridge（シェイプモーフで橋渡し） | route change | SVG path morph `d: path()` via WAAPI between equal-point paths (guard with `@supports (d: path("M0 0"))`; fallback: instant swap or a JS path morph), 700ms `cubic-bezier(.65,0,.35,1)`, fill and position interpolated; swap the scene while the shape covers the frame. | Shapes swap instantly. |
| glitch cut（グリッチ、RGBずれ） | route change | 5-8 `clip-path: inset()` slices with `translateX(±20px)` on `steps(1)` keyframes over 250ms, plus red and cyan offset copies with `mix-blend-mode: screen`; seeded offsets; at most 3 flashes per second. | Instant swap; no flashing. |
| ink bleed（インクブリード、インクリビール） | press | Overlay masked by an SVG `feTurbulence` + `feDisplacementMap` shape growing `scale` from the point over 900ms ease-out, or a `mask-image` blob scaled up; swap at full cover. | Instant swap. |
| brush wipe（ブラシワイプ） | route change | SVG mask with a thick `stroke-linecap: round` path animated by `stroke-dashoffset` 1 to 0 (`pathLength="1"`) over 700ms ease-out; rough edge by `feDisplacementMap`; apply `mask: url(#m)` to the new layer. | Instant swap. |
| letterform mask wipe（文字の中を抜けて次へ） | press | SVG `<mask>` or `mask-image` with a heavy glyph on the new layer, `scale: 1 to 60` with `transform-origin` on the letter, 1s `cubic-bezier(.7,0,1,.5)`; remove the mask at the end. | Instant swap. |
| gravity drop（グラビティドロップ） | route change | Old layer on top `translateY(0 to 110vh) rotate(4deg)`, 600ms `cubic-bezier(.55,0,1,.45)`; new layer in place beneath; `::view-transition-old(root) { z-index: 2; }` and `::view-transition-new(root) { animation: none; }`. | Crossfade only. |

## Text animations

| Name | Trigger | Web build | Reduced motion |
| --- | --- | --- | --- |
| split-text stagger（スタッガー） | load, enter view | Split into `span`s with `--i`; `@keyframes` from `translateY(0.6em); opacity:0`, 500 ms, `cubic-bezier(.2,.7,.2,1)`, delay `calc(var(--i)*40ms)` (20-80 ms); fire by adding a class from IntersectionObserver. GSAP `stagger: 0.04` if timelines are needed. | Remove the travel; one 150 ms opacity fade of the whole block, no stagger. |
| mask reveal (line rise)（マスクリビール、行マスク・せり上がり） | load, enter view | Line wrapper `overflow: hidden` (or `clip-path: inset(0)`), inner span `translateY(110%)` to `0` over 700 ms `cubic-bezier(.16,1,.3,1)`; vertical writing uses `translateX`/`translateY` along the block axis. Lines found by splitting on measured `offsetTop`; re-split on resize. | Show lines in place; optional 150 ms opacity fade. |
| blur-in / focus pull（ブラーイン、文字ブラーイン） | load, enter view | Per-word `filter: blur(16px)` to `blur(0)` plus `translateY(0.3em)`, 700 ms ease-out, stagger 60 ms. Blur forces paint per frame, so keep it to short headlines and drop `will-change` afterwards. | Opacity fade only, no blur, 150 ms. |
| scale punch（スケールパンチ） | enter view, state change | `animation: punch 450ms` with `scale(1.5)` to `1` using a `linear()` spring or `cubic-bezier(.34,1.56,.64,1)`; `display:inline-block` so transform applies; WAAPI `element.animate` for replays. | Instant final size; maybe a 150 ms colour change. |
| tracking-in（字間が縮まって入る、トラッキング・エクスパンド、トラッキング収束） | load, enter view | Animate `letter-spacing: 0.5em` to `0` with `opacity 0` to `1`, 900 ms ease-out. Letter-spacing triggers layout, so use a fixed-height block or scale a clone with `transform: scaleX` as a cheaper fake. | Static spacing, opacity fade 150 ms. |
| typewriter + caret（タイプライター、カーソル点滅タイプ） | load, enter view | CSS: `width` from `0` to `Nch` with `steps(N)` on a monospace line plus `border-right` caret with `animation: blink 1s steps(1) 5`, a finite count so the caret stops blinking after five seconds; or JS revealing grapheme spans every 50 ms. Keep the full text in a visually hidden copy. | Show full text at once; caret static or a slow opacity blink removed. |
| scramble / decode（スクランブル、スクランブル解読） | load, hover, enter view | JS timer (`requestAnimationFrame`, ~30 ms ticks) writing seeded random glyphs per grapheme, locking index `i` at `i*60 ms`; keep the real text in a visually hidden copy and mark the noisy spans `aria-hidden="true"` so readers skip the noise; `font-variant-numeric: tabular-nums` or monospace to avoid reflow. | Show the final text immediately. |
| word swap slot（ワード切り替えスロット、縦ロールで単語切替） | time, state change | Inline-block slot `overflow: hidden; height: 1lh`, inner stack of words moved by `translateY(-1lh * n)` every 2.5 s, 500 ms ease, stopping after two cycles or behind a pause button (it runs past five seconds); only the current word exposed to assistive tech (`aria-hidden` on others, `aria-live="off"`). | Swap the word instantly with a 150 ms opacity cross-fade; no auto-loop, or pause after one cycle. |
| odometer digits（オドメーター、オドメーター桁ロール） | enter view, state change | Per-digit column of `0-9` in a masked `1lh` window, `translateY(-d * 1lh)` with `transition: transform 1.2s cubic-bezier(.2,.8,.2,1)`, less travel for high digits via loop copies; a visually hidden copy holds the number, columns `aria-hidden="true"`. Library: Motion `animate` for state-driven values. | Show the final number directly. |
| count-up（カウントアップ） | enter view | IntersectionObserver then `requestAnimationFrame` tween eased by `1 - (1-t)**3` over 1.2 s, write `Math.round(v)` / `Intl.NumberFormat`; `tabular-nums` to avoid jitter; final value in markup so no-JS shows it. | Render the final value with no counting. |
| marker highlight（マーカーハイライト、マーカー強調） | enter view, scroll progress | `mark` with `background: linear-gradient(var(--c),var(--c)) 0 100%/0% 100% no-repeat`, transition `background-size` to `100% 100%` over 600 ms, or pseudo-element `scaleX(0)` to `1` with `transform-origin: left`; for wrapped lines add `box-decoration-break: clone`. | Band is already full, or fades in over 150 ms. |
| underline draw（アンダーライン描画、下線ドロー） | enter view, hover | Inline SVG path under the word with `stroke-dasharray: L; stroke-dashoffset: L` to `0`, 600 ms ease-out (`pathLength="1"` simplifies); for links use `background-size` on a gradient line. | Line fully drawn, no animation. |
| outline-to-fill（縁取りから塗りへ、輪郭→塗りスイープ） | enter view, hover | `-webkit-text-stroke: 1px currentColor; color: transparent`, then transition `color` to the fill, or overlay a copy with `clip-path: inset(0 100% 0 0)` to `inset(0)`; 700 ms ease-in-out. | Filled state shown at once. |
| gradient sweep text（グラデーションスイープ、シャイン・スイープ） | hover, enter view | `background: linear-gradient(110deg, base 40%, white 50%, base 60%) 200% 0/200% 100%; background-clip: text; color: transparent`, animate `background-position` to `-100% 0` over 2 s, one pass per trigger; provide `color` fallback via `@supports not (background-clip: text)`. | No sweep; plain colour. Never loop. |
| echo stack（エコースタック、エコートレイル字幕） | enter view, scroll progress | Stack 3-5 `aria-hidden` copies with `position:absolute`, each offset by `translate(0, n*8px)` or `translateZ` and `opacity: 1 - n*0.25`; animate with delay `n*60ms`; 600 ms ease-out. Original stays the only readable copy. | Drop the copies; show the single word. |
| karaoke highlight（カラオケ風ハイライト、カラオケ塗り） | time, scroll progress | Words in spans with `transition: color 200ms`; add `.lit` in order by `setTimeout` or `audio.timeupdate`; or scrub with `animation-timeline: scroll()` and `animation-delay` per word. Keep layout identical between states. | Show all words in the lit colour, no sequence. |
| kinetic lockup（キネティックロックアップ） | load, enter view | Per-word `--x`/`--y` start vectors, same `animation-duration: 600ms` and no delay difference, `translate(var(--x),var(--y))` to `0`, `cubic-bezier(.16,1,.3,1)`; container `overflow: clip` to avoid scrollbars. | Words in final place; 150 ms fade. |
| text as window（文字の窓抜き、テクスチャ/動画の流し込み、文字窓ズーム） | load, scroll progress | `background: url(...) center/cover; background-clip: text; color: transparent` and animate `background-position`/`background-size`; for video use an SVG `mask` with `<text>` or `mix-blend-mode: screen` black text over the video; keep `color` fallback. | Static image in the letters, no movement. |
