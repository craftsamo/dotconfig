# Element motion vocabulary

A dictionary, not a rulebook. It extends [core.md](core.md) with names for how a single element or a small group enters, moves, scales, rotates, reacts and draws attention. Each entry gives its Feel (one or two of the five words defined in [timing.md](timing.md) "## Feel"), For (what it is usually applied to), Looks like and The tell (the detail that makes it read as itself and how it differs from a near neighbour). How each entry is built in a rendered video is in [video/elements.md](video/elements.md).

## Entrance and exit

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| fade slide（フェード＋スライド） | smooth | UI, text | an element drifts a short way into place while it fills in from transparent, like a card sliding out of a mist | opacity and the drift finish on the same frame, and the slowing is strongest near the end so it settles quietly; the travel is small, which keeps it a drift rather than a flight — vs `soft rise`: no blur, and the offset can be sideways |
| soft rise（ソフトライズ） | soft | UI, text | a line of text lifts gently from just below, sharpening out of a haze as it settles, almost unnoticed | blur and transparency clear up during the rise and are gone just as the position lands; the lift itself is slight — vs `fade slide`: that one has no blur and reads crisper |
| snap in（スナップイン） | snappy | UI, logo | an element is simply there: it jumps in from a short way off and stops dead, like a switch flipping | nearly all the travel happens in the first instant and only a thin final gap closes, so the response feels immediate; the distance is short, close to the object's own size — vs `smooth arrival`: that one has a gentle exit from rest |
| split reveal（スプリットリビール） | snappy | logo, text | two cover panels meeting at the centre part sideways and open onto the subject, like lift doors | the two covers mirror each other in speed and distance, and the seam at the middle shows only briefly before the gap widens; the subject itself stays fixed — vs `slice reveal`: strips instead of two halves, and they offset |
| diagonal wipe（斜めワイプ） | snappy | UI, text | a slanted edge sweeps across a heading from the lower left to the upper right and uncovers it | the content stays put while the angled boundary travels, and the whole silhouette is released only at the very end of the sweep; it reads as strongly directional — vs `clip-path wipe`: that edge is straight and square to the frame |
| trail exit（残像アウト） | snappy | UI, character | an element accelerates away while a few fainter copies peel off behind it in the same direction | the main object leads and each copy follows slightly later and dimmer, so the trail reads as speed rather than a smear; the exit speeds up as it goes — vs `light trail`: these are echoes of a solid, not a streak of light |
| collapse away（折りたたみ退場） | heavy | UI, 3D | a panel folds down flat toward its base and fades, as if stowed into a slot below | the fold is anchored at the bottom so the height gives way toward the storage direction while opacity drops alongside; it stops short of a true zero scale until the very end — vs `shrink fade exit`: height only, from a base edge, not from the centre |
| 3d fold in（3D折り込み） | smooth | UI, 3D | a card stands up around its top edge, from a thin sliver in perspective into a flat frontal panel | the top edge stays fixed; only the lower part swings toward the viewer, and the back face is hidden so text reads the right way round throughout |
| shrink fade exit（縮小フェード退場） | soft | UI | an element contracts toward its own centre and thins out, ending as a small point that vanishes | size and opacity fall together with no sideways drift, and a faint blur softens the last stretch; nothing else on the layout moves — vs `soft shrink`: that one is a quiet downsizing with no blur and can rest at a smaller size |

## Movement

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| linear travel（一定速移動） | snappy | UI, 3D | an element crosses the frame at an even pace, like a part on a conveyor | no acceleration and no braking: the position advances at one rate, and the stop at the end is abrupt — vs `smooth arrival`: that one slows into rest |
| smooth arrival（なめらかな到着） | smooth | UI, logo | an element glides across and slows into its resting spot, like a sled onto a flat surface | speed is lowest at both ends and highest around the middle; the longer the distance, the longer it takes, and it adds no settle or overshoot — vs `snap in`: that one is almost all arrival in the first instant |
| arc travel（弧を描く移動） | smooth | character, 3D | an element moves between two points along a curve, rising to a high point near the middle and coming down | the highest point sits around the halfway mark, which reads as organic rather than the shortest path; the orientation can follow the tangent — vs `path follow`: this is one simple arch with no drawn route |
| anticipated move（予備動作つき移動） | bouncy | character, logo | an element eases a little backward, as if winding up, then launches forward and lands | the backward step is small and short next to the main move, and there is no full stall at the turn; it previews the direction of the action — vs `overshoot`: the extra move comes before the travel, not after |
| heavy stop（重い停止） | heavy | character, 3D | an object travels in and lands as if it had real mass: it squashes against the stop, then sinks into place | the weight shows only at the end — a squash along the direction of travel at the moment of arrival and a small settle that absorbs it while the position stays put — vs `smooth arrival`: no squash, it simply eases into rest |
| path follow（パス追従） | smooth | logo, 3D | an element rides along a drawn curve and turns with it like a bead on a wire | both position and heading follow the curve, so the turning continues smoothly; the heading turns wherever the route bends — vs `arc travel`: this one follows an actual drawn route |
| stagger follow（段差追従） | soft | UI, character | a chain of items trails the leader, each starting a fixed beat after the last, like a flock following | the same move repeats with a steady offset, so flow runs from first to last; the whole ends when the last item arrives, and each distance and ease are identical — vs `spring follow`: no overshoot, just a delay |
| magnetic snap（マグネット吸着） | snappy/bouncy | UI, logo | an element hangs back near a target, then is pulled the rest of the way in and clicks onto it | the travel is small at first and the gap closes almost all at once near the target, then a tiny overshoot settles back; a visible outline of the target marks where it lands — vs `overshoot`: the speed is late, not early |
| zigzag travel（ジグザグ移動） | snappy | character, 3D | an element moves forward while swinging up and down in a couple of sharp turns, like searching or dodging | forward progress is continuous and only the cross direction alternates; the turns are smaller than the forward distance — vs `arc travel`: sharp reversals instead of one smooth hump |
| momentum drift（慣性ドリフト） | smooth | UI, 3D | after a nudge the element coasts onward, rolls a little beyond its mark, then glides back and rests | the main travel is followed by a lingering coast and a soft return from a slight overshoot, like friction on a slick surface — vs `heavy stop`: no squash, just a long slide |
| waypoint hop（ウェイポイントホップ） | bouncy | character, UI | an element leaps between markers in little arcs, flattening a bit whenever it touches down | it lifts off ahead of every marker, touches down with a slight squash and carries on; the stops are few and the pace is brisk — vs `bounce landing`: each hop moves sideways onward rather than bouncing on the spot |

## Scale

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| pop scale（ポップスケール） | bouncy | UI, logo | an element grows from almost nothing, passes its full size slightly, and settles back | one clear overshoot above the base size and a short return, with a settle that takes up much of the move — vs `elastic scale`: one overshoot, not several decaying swings |
| breathing scale（呼吸する拡縮） | soft | UI, character | an idle element swells and relaxes in a slow, quiet cycle | the size drifts a little around its base, equal in each direction, and slowly, like breathing — vs `focus pulse`: continuous and gentle, not a one-off ring |
| elastic scale（エラスティックスケール） | bouncy | logo, character | an element is scaled and then wobbles in swings that get smaller, like a rubber toy | alternating overshoots shrink each beat while the spacing tightens slightly; the last correction is tiny — vs `pop scale`: several swings rather than a single rebound |
| axis stretch（軸方向ストレッチ） | bouncy | character, 3D | an element stretches long along its direction of travel and thins across it at top speed, then returns | the distortion peaks at the fastest moment and is back to normal at both ends; the volume looks preserved because the cross axis shrinks — vs `rubber band`: it stretches in step with the travel and is not pulled and released |
| focus pulse（フォーカスパルス） | snappy | UI, logo | a ring expands out of an element and fades, as a quick ping on a target | the element itself barely moves; the ring starts a bit smaller than it and thins to nothing as it grows — vs `focus halo`: this is a quick one-off ping, the halo is softer and slower |
| depth zoom（奥行きズーム） | heavy | 3D | a small, blurred element rushes toward the viewer, growing and sharpening, as if flying through space | the blur, scale and opacity resolve together, with a slow start and a heavy surge in the middle; it reads as travel in depth — vs `blur zoom`: heavier, with real perspective and a gradual start |
| soft shrink（ソフトシュリンク） | soft | UI, text | an element eases down in size and fades around a fixed centre, leaving without fuss | size and transparency drop in step around one anchor, and the speed rises toward the end — vs `shrink fade exit`: no blur, a plainer fade |
| impact squash（インパクトスクワッシュ） | heavy/bouncy | character, 3D | an element lands, flattens wide at the contact point, then springs back into its shape | the squash happens only at contact, compressing vertically and widening sideways, then the shape is restored; it is brief, not held — vs `heavy stop`: the squash is across the ground contact and it rebounds elastically |
| center punch（センターパンチ） | snappy/bouncy | logo, UI | an element bursts large from a tiny start at its centre, then rebounds once into place | it reaches its largest size quickly, one rebound then rest; the whole thing is decisive and compact — vs `pop scale`: faster and more forceful |
| width reveal（横幅リビール） | snappy | UI, text | a bar or label unfolds horizontally, starting from a pinned left side until it reaches full width | the anchored left side holds while the width grows, and the text fades in after the surface rather than stretching along with it — vs `lower third`: a lone bar, no layered plates |
| depth pullback（奥行きプルバック） | heavy | 3D | an oversized, bright surface drops back into the distance until the whole subject is visible | the scale falls from huge, the blur clears and the brightness settles together as the full silhouette appears — vs `depth zoom`: the direction is away from the viewer |

## Rotation

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| simple turn（シンプルターン） | smooth | logo, UI | an element rotates a half turn around a fixed centre and stops | slow at both ends and fastest in the middle; a marker or an asymmetric form on the shape shows the turn — vs `spin stop`: a single half turn with no spinning phase |
| spin stop（スピン停止） | snappy | logo, 3D | an element spins rapidly for a few turns, then slows and lands precisely on its angle | the deceleration is visible in the last stretch, and it lands on an exact intended angle, so a logo reads finished — vs `simple turn`: more turns and a hard start |
| pendulum wobble（振り子の揺れ） | soft | character, UI | an element swings from a pivot above it in arcs that shrink, like a sign on a hook | the pivot sits above the element so gravity reads; each swing alternates direction and gets smaller — vs `tilt reaction`: several decaying swings from a high hinge |
| coin spin（コインスピン） | snappy | logo, 3D | an element spins around its vertical axis like a coin, flashing a thin edge, and lands face on | face and edge alternate as the turns go on, and the last turn slows into a frontal stop; the mirrored back is brief — vs `card flip`: several turns, not a single flip |
| tilt reaction（チルトリアクション） | bouncy | UI, character | an element leans toward a touch like a plant bending to a hand, then rocks back to level, acknowledging it | the lean is quick and goes toward the input, the way home is slower with one small springy swing past level, and the position never travels — vs `pendulum wobble`: that swings several times from a high hinge, this answers a single poke |
| tumble in（タンブルイン） | snappy | logo, text | an element rolls in from off-frame and lands upright | position finishes first and rotation finishes slightly later, so the last stretch is a turn into place; the roll is a partial turn — vs `spin stop`: it also travels |
| counter rotation（カウンターローテーション） | smooth | logo, 3D | two nested parts turn in opposite directions about one centre | the outer and inner pieces mirror each other and balance; the inner piece is lighter than the outer — vs `gyroscope rotation`: one axis, two opposing directions |
| gyroscope rotation（ジャイロ回転） | smooth | 3D, logo | rings tilt and turn on different axes around one centre, like a gyroscope | two axes peak at different times and the centre object stays in place; each ring turns about its own axis — vs `counter rotation`: that one stays flat on one axis |
| rotate reveal（回転リビール） | snappy | UI, text | a surface swings open from its side like a hinged door coming round to face the viewer | the hinge side stays put as the narrow edge turns to the front, with opacity rising together — vs `3d fold in`: the hinge is at the side and the turn is about the vertical axis |

## Bounce and reaction

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| overshoot（オーバーシュート） | snappy/bouncy | UI, logo, text | an element runs slightly past its resting spot and eases back, like a door swinging a touch too far before it catches | the overshoot is only a small share of the whole travel, and the return leg is shorter and quieter than the main move, so it reads as a satisfied settle rather than a bounce — vs `anticipated move`: the extra distance lies past the target, not behind the start |
| bounce landing（バウンス着地） | bouncy | character, 3D | an element drops onto a floor and rebounds in hops that get lower and quicker, like a dropped ball coming to rest | every hop is lower and shorter than the one before and the object touches the floor between each, so the sequence runs down to stillness after a few contacts — vs `double bounce`: several diminishing hops instead of exactly two |
| spring follow（スプリング追従） | soft/bouncy | UI, character | a group trails its leader as if tied on invisible springs: each follower swings past the leader's stop and then catches up | followers pass the target one after another in order, then settle as the reaction fades, and the lag between leader and follower reads as mass — vs `stagger follow`: followers overshoot instead of only arriving late |
| rubber band（ラバーバンド） | bouncy | logo, character | an element is pulled along one direction, then released so it snaps back through its rest shape and wobbles flat | it elongates along the pull while thinning across, then compresses past neutral on release and the swings shrink each beat, the volume looking preserved throughout — vs `snap back`: several shrinking wobbles, not a single pass through rest |
| recoil（リコイル） | heavy | UI, character | an element is driven forward and kicks back like a gun, then drifts to a settled spot close to where it ended | the forward peak is clear and fast, the kick back is only a modest fraction of the distance, and the final correction is the shortest and slowest phase — vs `overshoot`: it travels in the opposite direction after impact rather than gently past |
| double bounce（ダブルバウンス） | bouncy | UI, logo | an element drops, rebounds once clearly, drops again, makes a small second hop and stops | there are exactly two rebounds, one large and one small, and the second ends with a clean stop that reads as complete — vs `bounce landing`: that one keeps going through several diminishing hops |
| snap back（スナップバック） | snappy/bouncy | UI, text | an element held in a stretched pose is let go and flicks home, passes neutral a little and settles | the return is much faster than the pull that preceded it and goes past rest once, briefly; the stretched pose is visible first, then released — vs `rubber band`: one flick past rest, not repeated wobbles |
| after shake（余震） | heavy | character, 3D | after a hit lands, the object keeps trembling in small tremors that fade like aftershocks | the first tremor is the biggest, directions alternate and each step is clearly smaller than the last, until the object is quite still |
| settle drop（沈み込み着地） | heavy | character, 3D | an object lands, sinks a little below its resting line and spreads sideways, then rises slowly back like a cushion recovering | the sinking is shorter than the fall, and the weight reads in the sideways spread and the slow recovery, not in any bounce — vs `impact squash`: slower recovery with no spring back |
| drag resistance（ドラッグ抵抗） | heavy/bouncy | UI, character | a dragged element lags behind the pointer, stretching as it is hauled, then shrugs back and rebounds once on release | the grabbed edge leads and the rest of the body trails behind it, which sells the weight; on release the stretch snaps back with a single short rebound |
| follow through（フォロースルー） | soft | character, logo | the main body halts while its loose parts carry on a moment longer, swing past and then settle | the core stops first, then the trailing parts overshoot once in rotation or stretch and return to neutral, each at its own pace — vs `spring follow`: that is separate bodies, this is parts of one body |

## Lists and grids

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| staggered list（リスト順次表示） | smooth | UI, text | rows of a list arrive one after another from top to bottom, like cards dealt onto a table | every row makes the identical move with the identical ease, and only the start moment steps down with a steady rhythm, so the list reads as a single even cascade — vs `cascade list`: no dip or settle, a plain even offset |
| cascade list（カスケード表示） | soft | UI, text | rows drop in from just above like a gentle wave, each coming to rest after the row above it | each row descends from a little overhead, dips fractionally past its slot and settles, so the wave has a soft landing at every step and still reads as one list — vs `staggered list`: the rows land with a tiny settle instead of a plain arrival |
| alternating list（左右交互イン） | snappy | UI, text | rows slide in from the left and right in turn, like a zip closing from both sides | the starting sides alternate row by row while every row finishes on the same vertical axis, so the stack ends in a single column after the zigzag entrance — vs `staggered list`: the start side alternates instead of staying the same |
| row expand（行の展開） | bouncy | UI, text | a row opens from a thin line into its full height to reveal detail, like a drawer sliding out | the row opens from its top edge and a mask or vertical scale uncovers the content while the rows below make room, with a small overshoot at the end; the neighbours above stay still |
| grid wave（グリッドウェーブ） | soft | UI, 3D | cells rise one after another as a single wave that crosses the grid from one corner | the delay is set by row plus column, so there is one readable wavefront, and cells in the same diagonal are in step — vs `grid diagonal wave`: a soft rise rather than a hard sweep of snappy arrivals |
| center-out grid（中央から展開） | bouncy | UI, logo | cells appear at the middle of the grid and spread outward in rings, like a ripple frozen into tiles | the middle cell resolves first and rings of increasing distance follow in turn, each with a small overshoot; the layout stays fixed |
| row sweep grid（行スイープ） | snappy | UI, 3D | the grid fills in row by row, like a printer laying down lines | cells inside a row arrive almost together, then the rhythm steps to the next row, so the motion reads as horizontal bands moving down — vs `grid diagonal wave`: whole rows arrive together, not a slanted front |
| shuffle to grid（シャッフル整列） | snappy/bouncy | UI, 3D | scattered, tilted tiles fly in from disorder and lock into an orderly grid | tiles start at varied positions and angles, travel with different speeds, and converge at the same moment onto equal spacing, so the end feels like order emerging |
| list slide stack（リスト積み重ね） | smooth | UI | a new row slides in at the top while older rows shift down by one place, like a feed receiving a post | rows glide into slots top-down and every older row steps down by exactly one row height at the same moment as the arrival; nothing jumps |
| list trim collapse（リスト削除詰め） | smooth | UI | a removed row shrinks away and the rows beneath close the gap | the removed row loses opacity and height first, then the followers move up by one step to fill the space, so the order of events reads as delete then tidy |
| grid spiral（グリッド螺旋展開） | smooth | UI, 3D | tiles show up along a spiral winding outward from the middle | delay follows position along the spiral rather than radial distance, so the reveal visibly turns around the centre while all tiles end in an identical state — vs `center-out grid`: a single winding path instead of rings |
| grid diagonal wave（グリッド斜めウェーブ） | snappy | UI | a diagonal line of change crosses the grid from one corner to the opposite one | cells on one diagonal arrive together because the delay is row plus column, giving a crisp slanted front — vs `grid wave`: sharper and quicker, without the soft rise |

## Attention and emphasis

| Name | Feel | For | Looks like | The tell |
| --- | --- | --- | --- | --- |
| nudge（ナッジ） | snappy | UI, text | an element gets a small shove sideways and is back in place almost at once, like a tap on the shoulder | only the target shifts while everything around it holds still, and the return is a touch softer than the push, so it reads as a gentle poke rather than a move — vs `error shake`: one push and return, no repeated swings |
| attention bounce（アテンションバウンス、注目バウンス） | bouncy | UI, character | an element hops once on the spot, as if jumping to be noticed, and lands with a little squash | one lift and one short landing, with the position unchanged at the end; the squash at touchdown is what makes it feel alive — vs `bounce landing`: a single hop in place, no run of diminishing rebounds |
| badge pop（バッジポップ） | bouncy | UI, text | a small badge jumps onto the corner of an icon, like a notification dot appearing | only the badge animates, growing from nothing past its size with a slight tilt, while the base element stays completely still — vs `pop scale`: only the small badge pops, not the element itself |
| focus halo（フォーカスハロー） | smooth | UI, logo | a soft ring blooms around a target and fades, like a ripple under a lamp | the ring grows concentric with the target and thins out slowly, and the target itself holds still — vs `focus pulse`: slower and softer, the pulse is a quick sharp ping |
| highlight sweep（ハイライトスイープ） | smooth | UI, text | a band of colour passes across a row once, like a marker run over a line | a slanted band crosses while the underlying text and shape stay fixed, and the colour is visible only inside the element — vs `light sweep`: a coloured marker band over text, not a glossy highlight on a surface |
| border chase（ボーダーチェイス） | snappy | UI, logo | a short bright segment runs around a box's edge, like a marquee light | one short bright piece circles all four edges at one steady pace and the rest of the border stays dim, so the eye follows the single runner — vs `marching dashes`: one bright runner on a dim border, not a whole line of moving dashes |
| press feedback（プレスフィードバック） | snappy | UI | a button dips as if pressed by a finger and then springs back | the compression and the loss of shadow happen together, then the return is quick; a drawn cursor ring marks where the press landed — vs `nudge`: the press goes inward in scale, not sideways |
| jelly emphasis（ゼリー強調） | soft/bouncy | logo, character | an element wobbles once like jelly being tapped, wider then taller then back | horizontal and vertical stretch alternate and each swing is smaller than the last, while the centre stays put — vs `elastic scale`: it wobbles around a size it already has rather than growing into it |
| color pulse（カラーパルス） | soft | UI, logo | an element swells in colour and relaxes back, like a slow heartbeat of tint | position and size stay as they are; only the accent brightens and then eases back to the base colour — vs `glow pulse`: the colour itself shifts, no halo appears |
| icon nod（アイコンうなずき） | bouncy | UI, character | an icon bows forward and comes back up like a head giving a polite nod of agreement | the pivot sits at the top, so the lower edge swings toward the viewer while the top stays put; the way back is a smaller, quieter swing and it ends level — vs `attention bounce`: that hops the whole icon on the spot, this one only rocks about a hinge |
| spotlight focus（スポットライトフォーカス） | smooth | UI, logo | the frame dims while one element stays lit, like a stage light picking out a speaker | a cut-out in the dim layer glides onto the target and opens up around it, so the rest of the frame recedes while the target keeps full brightness — vs `kpi spotlight relay`: one target is lit, with no handover between figures |
| error shake（エラーシェイク） | snappy | UI, text | an element shakes sideways in a quick refusal, like a head shaking no | the first kick is the largest and each swing is clearly smaller than the previous, and a red outline stays after the shake ends — vs `after shake`: horizontal only and tied to a red state |
