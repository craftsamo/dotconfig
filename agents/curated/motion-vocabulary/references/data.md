# Paths, diagrams and data vocabulary

A dictionary, not a rulebook. It extends the core `core.md` with drawn paths, strokes, charts, maps and the moments that turn numbers into a story. Everything is performed by the timeline inside the frame: a hover, click, drag or scroll is a tween the timeline plays, drawn as a cursor, a finger or a moving page, never a real input. The Feel column uses the five feel words defined in `timing.md` "## Feel" (smooth / snappy / soft / heavy / bouncy). For says what an entry is usually applied to; The tell names the detail that makes it read as itself and how it differs from a near neighbour.

## SVG and paths

| Name | Feel | For | Looks like | The tell | Built with |
| --- | --- | --- | --- | --- | --- |
| svg stroke draw（SVG線描画） | smooth | logo, UI | an outline draws itself, as if a pen were tracing it in one pass | the stroke head advances in path order and leaves the complete outline behind it; the line is hidden ahead of the head — vs `signature stroke`: one path at one pace, not strokes joined in a writing order | the path's `stroke-dasharray` is set to its length and `stroke-dashoffset` is tweened from full length to zero on `power2.out`; fill, if any, fades in after |
| svg path morph（SVGパスモーフ） | smooth | UI | one outline turns smoothly into another, like clay being reshaped | contour points slide to nearby counterparts without crossing over each other, so the in-between shapes stay clean rather than tangled — vs `liquid morph`: crisp contours throughout, not a blobby merge | a tween of the path `d` between two paths with matching point counts and order, on `power2.inOut`, ending on the target path |
| svg segment trim（区間トリム） | snappy | logo, UI | a visible piece of a path slides along it, like a bead of light running a track | a fixed-length piece travels while its tail disappears at the same rate as its head advances, so the length stays constant — vs `border chase`: any path, with ends that trim, not a lap around a box | `stroke-dasharray` set as a short dash and a gap, with `stroke-dashoffset` moved along the path on `power2.inOut` |
| svg motion path（モーションパス追従） | smooth | UI, character | an item travels along a path and turns with it, like a car on a track | the item's centre stays exactly on the path and its rotation follows the local direction of the curve, so it banks through bends — vs `path follow`: the route itself is an SVG path with its own geometry | the item is positioned from the path by a progress value with tangent rotation, tweened on `power2.inOut`; the final point is the path's end |
| svg mask reveal（SVGマスクリビール） | soft | logo, text | a shape grows as a mask and uncovers the artwork underneath, like a spotlight opening | the content stays still and only the mask boundary grows, past full size by the end so no part of the art stays hidden — vs `iris / circle reveal`: the mask can take any drawn shape, not only a circle | a mask element on the artwork, its shape scaled from small to past full on `power2.out` around a chosen centre |
| svg gradient flow（グラデーション流動） | smooth | logo, 3D | colour seems to flow along a line, like liquid moving through a pipe | the stroke itself stays fixed and only a bright band travels along it at an even pace, in one direction — vs `marching dashes`: the colour band travels along a fixed line, no dashes move | gradient stops or `gradientTransform` tweened along the line with `none` ease, a finite number of loops |
| gooey merge（グーイーマージ） | soft | logo, 3D | blobs that touch fuse and part like liquid drops | a narrow bridge forms when two blobs get close, then merges into one contour and later pulls apart into a thread before it breaks | a blur followed by a colour-matrix contrast filter over moving circles on a drawn layer, on `power2.inOut`; the final frame is a clean shape |
| signature stroke（署名ストローク） | smooth | logo, text | handwriting is written in one pass, as if signed with a pen | each stroke flows into the start of the next, in the order a hand would write, with rounded ends — vs `svg stroke draw`: several strokes chained in writing order | several paths each with a dash offset tween in writing order, round caps, on `power2.inOut`, with each starting as the last finishes |
| radial repeater（リピーター） | smooth | logo, UI | one shape is copied around a centre like petals, forming a flower or wheel | the copies rotate and offset in time, so the pattern keeps shifting like a kaleidoscope while the centre stays still | clones placed at an even angle step around a pivot with staggered scale or rotation on `sine.inOut`, ending at a settled arrangement |
| noise blob（ゆらぐブロブ） | soft/smooth | UI, logo | a blob whose edge wobbles slowly, like a drop of oil | the outline swells and shrinks at different rates in different places, so it reads as an organic form rather than a plain circle being scaled — vs `breathing scale`: the shape of the edge changes, not just the size | path points moved by a seeded noise list over a looping time axis, with the loop closing on its first frame |
| radiating burst lines（集中線、放射の線） | snappy/bouncy | UI, logo, character | straight lines fan out from a point, like a comic burst of emphasis | the lines extend one after another and then vanish from their base end, so the burst looks thrown outward and gone | a set of lines from one origin, extended on `power2.out` with a stagger and erased from the base; lengths vary by a seeded list |
| marching dashes（破線が流れる） | smooth | UI | a dashed line whose dashes crawl along it in a file, like a column of ants following a trail | the pattern flows in one direction at an even pace, every dash keeping its shape and spacing, while the line itself does not move or grow — vs `border chase`: that is one bright runner on a dim border, here every dash travels and the whole line is lit | a path with a dash pattern whose offset tweens by exactly one pattern length on `none` ease, so the loop seam is invisible; a finite number of loops, then the line stops |

## Data storytelling

| Name | Feel | For | Looks like | The tell | Built with |
| --- | --- | --- | --- | --- | --- |
| sankey flow reveal（サンキー流量リビール） | smooth | UI | flowing bands fill from source nodes to target nodes, their thickness showing the amounts, like pipes filling with coloured water | the bands run in order from the source side to the target side and their width carries the value, so thick flows read as large at once; the fill front travels with the flow direction | band paths drawn with a dash offset from the source end on `power2.inOut`, stroke widths set from the data and the node labels fading in just before |
| metric odometer cascade（指標オドメーター） | smooth | UI | several metrics roll their digits like odometers, one metric after another, each ending on its figure | each metric rolls in turn and settles on its final digit, the units digit turning fastest and the leading digits slowest, so the last figure locks in a beat apart from the next | per-digit vertical columns of numerals moved in y with a stagger between metrics on `power2.inOut`; each column ends aligned on its target digit |
| threshold alarm wave（閾値アラーム波） | smooth | UI | a line crosses a limit and the alert colour spreads out from the crossing, like a stain | the colour starts exactly at the crossing point and travels outward from there along the chart, while the rest of the chart keeps its calm palette until the wave reaches it | the line draws past a marked limit; at the crossing a colour ring on a drawn layer expands from that point on `power2.out` and tints the line it passes |
| forecast confidence fog（予測信頼度フォグ） | heavy | UI | the future part of a line sits inside a haze that widens with distance, like fog thickening ahead | the haze starts almost thin at the present point and grows wider and softer the further into the future it goes, so uncertainty reads as spatial | a blurred band around the forecast path, its width and softness growing along x on `expo.out`, drawn on a layer beneath the line |
| live signal pulse map（ライブ信号パルスマップ） | smooth | UI | dots on a map send out pulse rings as events occur, like sonar pings | pulses start at different points at different moments, and a ring fades as it grows so that several can overlap without clutter | pulse rings at seeded points on a fixed schedule, scale up with opacity down on `power2.out`, a finite number of events in total |
| comparison delta split（比較デルタ分割） | smooth | UI | two values start together, then separate and the gap between them is bracketed and labelled | the gap opens from a shared baseline, then a bracket closes around it and the difference number appears just after the move ends, so the number follows the visual | two bars move apart on `power2.inOut`, a bracket drawn along the gap, and the difference figure fades in beside it |
| timeline scrub trail（タイムライン軌跡） | smooth | UI | a playhead moves along a timeline and leaves a trace of earlier values behind it | the dot at the front is the brightest, while earlier parts of the line fade behind it, so the eye tracks the present moment | a line drawn left to right with a cursor dot at its head, the older portion fading by opacity along its length, on `none` ease |
| network topology bloom（ネットワークトポロジー展開） | bouncy | UI | a network grows from one node outward, like a root system spreading | nodes pop in order of their depth from the first one, and each edge is drawn out toward its node just before it appears | nodes popped by scale on `back.out` with a stagger by depth, edges drawn by dash offset outward from the parent layer by layer |
| progress milestone firefly（進捗マイルストーン蛍） | smooth | UI | a glowing dot travels along a track and lights each milestone as it passes, like a firefly on a trail | each milestone glows at the moment the dot reaches it and remains lit, while those ahead stay dim | a dot moving along the path by progress on `power2.inOut`, each milestone's glow layer fading up on arrival, finishing at the last one |
| heatmap ripple focus（ヒートマップ注目波） | bouncy | UI | the hottest cell pulses and a ripple spreads across its neighbours, like a drop on a grid | neighbours react less the farther they are from the centre, so the response fades with distance from the cell | a ring from the hot cell, with each neighbour's scale pop reduced by its distance on `back.out`, and the grid ending at rest |
| stream graph breathing（ストリームグラフ呼吸） | smooth | UI | layered bands swell and thin in a slow loop, like a stream graph breathing | each band changes thickness at its own pace while the stack as a whole holds a steady outline, so the layers seem to exchange volume | stacked paths morphed between two sets of values on `sine.inOut` for a finite number of repeats, ending at the first set |
| rank ladder climb（順位ラダー上昇） | snappy | UI | an item climbs the ranking and the others shift down to make room | one item jumps up several places while the others step down by one place each, so the swap reads as a climb | y tween per row to its new position on `power2.out`, the climbing row lifted slightly in front and the numbers updating at the end |
| data cluster merge（データクラスタ結合） | bouncy | UI | groups of points pull together into one cluster, like filings drawn to a magnet | the points overshoot the centre slightly and fall back, so the cluster briefly looks tighter than its final size | points tweened to a shared centre with small offsets on `back.out`, one colour taking over from the groups at the end |
| event sequence domino（イベント列ドミノ） | heavy | UI | events on a line fall one into the next, like dominoes | each item tips against the next so the sequence seems to carry a push along the line, its force building with the chain | per-item rotate or drop on a stagger on `expo.out`, with each starting as the previous reaches the next |
| kpi spotlight relay（KPIスポットライトリレー） | smooth | UI | a spotlight passes from one key figure to the next, like a baton | the previous figure dims at the same time as the next one lights, so the attention is handed over rather than switching off between them — vs `spotlight focus`: a handover between several targets, not a single one | a moving light pool on a drawn layer glides between the figures while the old one's brightness falls and the new one's rises |
| radial budget bloom（放射予算ブルーム） | smooth | UI | ring slices open out around a centre, sized by their share of the budget | the slices grow one after another round the ring and their labels count up in step with the arc length | arcs by `stroke-dashoffset` on a stagger around the ring, each ending at its share, labels counting up with it |
| calendar density sweep（カレンダー密度スイープ） | snappy | UI | a sweep colours calendar cells by how busy each day is, like a heat tint passing over the month | the cells fill in order across the rows, and the busiest days end up in the deepest colour while the quiet days stay pale | per-cell fill with a stagger across rows on `power2.out`, with colour intensity set from the data |
| live queue compression（ライブキュー圧縮） | bouncy | UI | items line up into a queue that squeezes as the line advances | each arrival squashes slightly against the one in front and the rest shift forward by a step | row items moved in x steps, with a small squash on arrival on `back.out`, the queue ending evenly spaced |
| sentiment spectrum shift（感情スペクトラム遷移） | smooth | UI | a marker slides along a colour spectrum as the mood changes, like a needle on a gauge | the gradient bar stays fixed while only the marker moves, and the label swaps while it passes the midpoint | a marker tweened in x over a fixed gradient on `power2.inOut`, with the label crossfading as it goes |
| goal projection arc（目標予測アーク） | smooth | UI | a dashed arc stretches from today's point toward a faraway goal, like a flight route being drawn on a map | the dashes extend steadily from the start with the head leading, and the goal marker stays hidden until the arc lands, then pops once at the end — vs `svg stroke draw`: that traces a solid outline, this one is dashed, aims at a target and finishes with a marker | an arc path dashed by a pattern and revealed with a mask or clip growing along it on `power2.inOut`, then an end marker scaled up on `back.out`; ends still |
| scatter reveal（散布図が現れる） | smooth | UI | dots appear across the axes, and a trend line is then drawn through them | the points come first in a loose scatter and only then does the line draw, so the pattern is revealed after the evidence | dots in a seeded order on a stagger on `power2.out`, followed by a line drawn left to right |
