# 表記の既定値

この表記は、Microsoft の日本語スタイルガイド (Japanese Localization Style Guide、2025 年 7 月版の PDF、<https://aka.ms/japanese-styleguide>) に合わせた既定値です。
ガイドはソフトウェアの翻訳向けに書かれているため、UI 文字列に固有の決まりは地の文へ広げません。
ガイドが扱っていない点と、ガイドの中で表記が揺れている点は、このファイルで既定を決めています。

## 優先順位

1. 依頼で指定された表記、文書やリポジトリの規約、媒体の規定を優先します。
2. 既存の文書を直すときは、文書全体で一貫している表記に合わせます。
   たとえば和欧間にスペースを入れない書き方 (JTF 日本語標準スタイルガイドなど) で統一された文書なら、そのまま保ちます。
3. 指定も既存の一貫した表記もないときに、このファイルの既定値を使います。

引用、固有名詞、商標、識別子、コマンド、ファイルパスは、変更を求められていなければ原文の表記を保ちます。
inspector の notation モードは、この既定値からのずれを候補として返します。
別の規約に従う文書では、その指摘を「規約に従って残す」と判断して構いません。

## N1 和欧間のスペース

全角文字と半角文字の間には、原則として半角スペースを入れます。
英字だけでなく、算用数字とインライン コードも半角文字として扱います。

- 「Git の履歴」「Word を使用するときは」「Shift キー」
- 「第 3 章」「1 つ」「3 か月」「2026 年 10 月 3 日」「約 50%」
- 「`git status` を実行します」

次の場合はスペースを入れません。

- 「、」「。」と半角文字の間:「クリックして、Windows を再起動します」
- 括弧や引用符の内側:「列 A (タイトル)」であって「( タイトル )」ではありません。「「test」と入力します」
- スラッシュの前後:「3/14」「オン/オフ」
- 語の終わりの「?」「!」「:」「...」と、その前の全角文字の間:「更新しますか?」「注意:」
- 数字と「%」「°」の間:「50%」「45°」

全角文字どうしの間には、スペースを入れません。
ただし英語の複合語を写したカタカナ語 (N6) と、文書内の章を参照するとき (「「第 2 章 コントロール」を参照してください」) は例外です。
全角スペース (U+3000) は使いません。

## N2 数字と単位

- 算用数字は半角で書きます。全角数字は使いません。
- 数字と単位の間には半角スペースを入れます:「100 MB」「3 kg」「250 ms」「1.5 インチ」。
- 「%」と「°」は数字に付けます:「50%」「45°」。
  ガイドに定めのない「℃」も、同じく数字に付けて「20℃」とします。
- 3 桁区切りは半角コンマ、小数点は半角ピリオドです:「2,000 ページ」「1.5 倍」。
- 時刻は半角コロン、日付の区切りは半角スラッシュです:「12:30」「2026/10/3」。
  地の文では「2026 年 10 月 3 日」のように年月日で書いても構いません。
- 範囲は「から」で書きます:「0 から 99 mm」。波ダッシュ「〜」「～」は使いません。
  単位は後ろの数にだけ付けても (「100 から 200 MB」)、両方に付けても (「100 MB から 200 MB」) 構いません。文書の中でそろえます。

## N3 句読点と約物

- 句読点は「、」「。」です。「，」「．」は使いません。
- 疑問符、感嘆符、コロンは半角の「?」「!」「:」です。
  前の全角文字との間は詰め、後ろに文が続くときは半角スペースを入れます:「保存しますか? 保存しない場合は...」。
- 感嘆符は、強すぎると感じたら外します。説明文では「。」で終えるのが基本です。
- 見出しや項目の終わりのコロンは使えます:「注意:」「この操作を行うと:」。
- セミコロンとアンパサンドは、英語の引用や固有名詞の一部としてだけ使います。
  「&」は読み上げで意味が伝わりにくいため、地の文では「と」「および」と書きます。

## N4 括弧と引用符

| 記号 | 用途 | 例 |
|---|---|---|
| 半角 ( ) | 補足説明、未翻訳の UI 用語への訳、電話番号、アクセス キー | 「[View] (表示) をクリックします」「保存(S)」 |
| 「 」 | 引用、章や節の題名、入力する文字列、ファイル内の文字列 | 「「セキュリティ」を参照してください」「「setup」と入力します」 |
| 『 』 | 書籍、資料の題名 | 『運用ガイド』 |
| “ ” | 画面に表示される文字、強調する語、フィールドやプロパティの名前 | 「これを “リボン” と呼びます」 |
| 半角 [ ] | ラベルのある UI 要素 | 「[OK] をクリックします」 |

- 半角括弧の外側は、隣が全角文字なら半角スペースを入れます。内側にはスペースを入れません。
- UI のアクセス キー「保存(S)」と、商標の「Microsoft(R)」は詰めます。
- 全角の「( )」は使いません。
- 一覧として並べる語には「」を付けません。
- 地の文で直線の二重引用符「"」は使いません。

## N5 記号

- スラッシュは半角で、前後を詰めます:「オン/オフ」。
- ダッシュ (「—」「–」「―」「──」) は日本語の地の文と見出しでは使いません。
  補足には括弧、文の区切りには句読点、見出しと説明の区切りにはコロンを使います。
  引用、コード、欧文の固有表記は対象外です。
- 省略記号は半角ピリオド 3 つ「...」です。「…」「‥」は使いません。
- 「+」はショートカット キーの区切り (「Ctrl+C」) と式で使います。地の文では「プラス」「と」と書きます。
- 全角の英記号 (「％」「＃」「＆」「／」など) は使いません。

## N6 カタカナ

**長音**: 英語の語尾が -er、-or、-ar の語は、語尾に長音「ー」を付けます。
「コンピューター」「ユーザー」「サーバー」「フォルダー」「プリンター」「ブラウザー」「パラメーター」と書きます。
それ以外の語尾は、長音を数えて 3 文字以下なら付け、4 文字以上なら付けません。
小さい「ャュョッァィゥ」は数えません。
「メニュー」「キュー」には付け、「メモリ」「カテゴリ」「ディレクトリ」「セキュリティ」「プロパティ」には付けません。

慣用でこの規則に従わない語は、ガイドの例外表に従います。
「プロセッサ」「コンパイラ」「コネクタ」「スケジューラ」「レジスタ」「プログラマ」「エンジニア」「ボランティア」「ストーリー」「ポリシー」「ギャラリー」などです。
「インターフェイス」は「インタフェース」「インターフェース」と書きません。

**複合語**: 英語でスペースを挟む複合語は、カタカナでも半角スペースで区切ります。
「ダイアログ ボックス」「メニュー バー」「タスク バー」「コントロール パネル」です。
英語でハイフンや 1 語で書く語は続けます:「ダブルクリック」「マルチバイト」「ログオン」。
英語の語源が分からない語や、一般に続けて書くことが定着した語 (「ホームページ」「スマートフォン」) は、続けて書いて構いません。

**中黒**: 「・」は外国の人名、社名、国名、言語名などの区切りに使います:「トリニダード・トバゴ」。
カタカナ複合語の区切りや、日本語の語を並べる区切りには使いません。並べるときは「、」を使います:「速度、容量」。

**半角カタカナ**: 使いません。

## N7 漢字とかな

常用漢字表と「送り仮名の付け方」の本則に従います。
「行う」「表す」「変わる」と書きます。

ガイドは個別の語の書き分けを『用字用語 新表記辞典』に委ねています。
このスキルでは、指定がない限り次の語をかなで書きます。

| かなで書く | 書かない | 条件 |
|---|---|---|
| ください | 下さい | 「〜してください」の補助的な用法 |
| いただく | 頂く | 「〜していただく」の補助的な用法 |
| できる | 出来る | 可能の意味。「出来事」「出来上がり」は漢字 |
| とき | 時 | 「〜するとき」の形式名詞。時刻の「時」は漢字 |
| こと | 事 | 「〜すること」の形式名詞 |
| など | 等 | 例示。「等しい」「平等」は対象外 |
| ため、ように、とおり | 為、様に、通り | 形式名詞としての用法 |
| および、または、ならびに、ただし、さらに、すでに、あらかじめ、ほとんど | 及び、又は、並びに、但し、更に、既に、予め、殆ど | 接続詞や副詞 |
| 〜してみる、〜していく | 〜して見る、〜して行く | 補助動詞 |

実質的な名詞や動詞としての用法、引用、固有名詞は機械的に置き換えません。

「自動化」「具体的」などの「〜化」「〜的」は自然な表現として使えます。
抽象的な語が重なって意味を取りにくいときは、何をどうするのかを動詞で書きます。

## N8 数字の書き方

- ほかの数に置き換えられる数は算用数字で書きます:「1 つ」「1 月」「(雑誌を) 1 部」。
- 置き換えられない数や慣用句は漢数字で書きます:「もう一度」「一時的に」「四捨五入」「(画面の) 一部」「一般」「統一」。
- 助数詞の「か」と「個」はカタカナにしません:「3 か月」「5 個」であって「3 ヶ月」「5 コ」ではありません。

## N9 文体と敬語

- 説明の本文は「です・ます」です。操作を求めるときは「〜してください」と書きます。
- 見出し、表の項目、図のキャプションは体言止めか「である」で書きます。見出しを「〜します」で終えません。
- 同じ水準の要素 (見出しどうし、箇条書きの項目どうし) は文体をそろえます。
- 尊敬語と謙譲語は基本的に使いません。顧客に向けた文書では使い、「弊社」「お問い合わせください」「ご確認ください」と書きます。
  その場合も「ご使用にならないよう」「お使いいただくときには」のような過剰な敬語は避けます。
- 確認を求める問いは「〜しますか?」と書き、「〜してもよろしいですか?」は使いません。
- 読み手への呼びかけは、まず省略を考えます。必要なら「ユーザー」「管理者」など役割で書きます。
  「あなた」は文脈によっては失礼に響くので、使う場面を選びます。
- 書き言葉の硬い表現より日常の語を使います:「〜が可能です」より「〜できます」。
  英語の列挙を写した「A、B、および C」は「A、B、C」と書きます。
- 「各〜ごと」は重複なので「各〜」か「〜ごと」のどちらかにします。
- 根拠のない最上級 (「完璧な」「最高の」「世界一」) と主観的な強調 (「非常に」「とても」) は使いません。
- 「適当な」は「いいかげんな」とも読めるため、「適切な」と書きます。
- 「名詞 + を実行します」は、自然な「〜します」にできるなら動詞で書きます:「インストールします」。
- 使役の「〜させる」は必要なときだけ使います。「起動」を「立ち上げる」のような業界用語で書きません。

## N10 包摂的な表現

- 性別を前提にした職業名は避けます:「看護師」「客室乗務員」「保育士」「営業担当者」。
- 読み手を「初心者でも」のように能力で区分しません:「初めての方も」。
- 技術用語でも、置き換えの定まった語は置き換えを使います:「プライマリ/セカンダリ」「許可リスト/拒否リスト」。
  プロトコル名や引用など、原文どおりに書く必要がある語はそのまま保ちます。

## N11 Markdown の書式

- 太字の「**」が日本語の約物に接していると、CommonMark では太字にならない場合があります。
  「**「重要」**です」のように、強調の内側が括弧や約物で始まって外側に文字が続く形は避け、括弧を外に出すか、外側に半角スペースを入れます。
  inspector の expression モードの bold_not_rendered が、この形と直し方を返します。
- 強調はガイドでは “ ” を使います。Markdown の文書では太字を使って構いませんが、1 つの段落で 1 か所程度にします (constitution.md 第 6 条)。
- 箇条書きは、本当に並列の項目だけに使います。手順は番号付きの一覧にします。
