# Scenario: new project (greenfield)

Apply on top of the general spine when starting from scratch (no existing system/data to preserve).

## Clarify scope & constraints
- Goal, users, must-haves vs nice-to-haves, constraints (stack, deadline, hosting, budget).
- Success criteria for a first usable version.

## Choose the shape
- Pick stack/structure deliberately; favor boring/proven defaults; justify non-obvious choices.
- Identify the smallest end-to-end slice (MVP) that delivers the core value.

## Scaffold & iterate
- Stand up a minimal skeleton first (structure, deps, run/test, README).
- Build the MVP slice end-to-end before breadth; keep it runnable at each step.

## Gates
- [ ] Scope + success criteria agreed (MVP defined)
- [ ] Stack/structure chosen with rationale
- [ ] Runnable skeleton before feature breadth
- [ ] MVP slice works end-to-end
