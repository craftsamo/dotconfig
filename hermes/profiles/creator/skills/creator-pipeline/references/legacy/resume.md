# Salvage — recovering another effort's work (entry reference)

This reference applies to resident sessions. Discipline: **work that already
cost credits is raw material, never waste**. <Salvage> covers a session asked
to recover another effort's surviving work.

## Salvage — recovering another effort's work (intent)

The session's job is to rescue, complete, or canonicalize assets an earlier
effort already paid for (an interrupted batch, surviving assets needing a canonical
export, work stranded by a crash).

1. **Locate the source** — the brief must point at it: the previous session's
   artifact paths and/or a preserved durable job directory. Missing
   provenance → ONE batched question in the reply; never regenerate what the
   task says already exists.
2. **Inventory BEFORE any spend** — list every surviving artifact and its
   state (complete / needs post-processing / genuinely missing). State the
   inventory in the reply: it is the salvage plan and the evidence for the
   verify gate.
3. **Classify each item**: reusable as-is → post-process/export only
   (ffmpeg, scripts — costs nothing); incomplete → finish from the locked
   anchor; genuinely missing → produce fresh (`references/legacy/produce.md`),
   counted against this session's Budget.
4. **Canonicalize** — exact target specs (dimensions, format, naming) per
   the brief; the point of salvage is usually turning surviving assets into the
   one true set.
5. Verify per `references/legacy/verify.md` (salvage profile: the gate is the
   inventory trail — nothing regenerated that existed), deliver per
   `references/legacy/delivery.md`.

## Pitfalls

- Regenerating what already survives — inventory before spending, always.
- Salvage without provenance — "close enough" regeneration drifts the set
  and double-spends.
- Treating salvage's missing pieces as a fresh brief — the inherited
  anchor still governs style; only the spend is new.

## Verification

- The inventory ran before any generation; nothing that survived was
  regenerated.
- Inventory stated in the reply, every fresh spend maps to a genuinely
  missing item.
