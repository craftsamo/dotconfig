# Commission and accept parts

Writer owns post, article, copy, document, message and script prose through its
`write-*`, `edit-*`, `analyze-*` leaves. X posts use `write-post` / `edit-post` /
`analyze-post`; promotional text uses `write-copy` / `edit-copy` / `analyze-copy`;
Substack, note and Zenn articles use the matching article operation. Select from
the request, not a filename. A supported custom destination is not evidence
that its editor supports a given import or that browser saving is verified.

Give Writer the actual brief, source/target for edit or analysis, reader/purpose,
protected wording, decided claims/conditions, required structure and media
references. Ask only for the released unit. Do not request invented experiences,
proof or a generic style transformation. Existing accepted text is reusable if
its bytes, purpose and evidence still match; do not rewrite for activity's sake.

A Writer candidate is not writing-QA-gated merely because a peer returned it.
Marketer, as requester, loads Writer's shared acceptance and applicable prose/script
contract through [content QA](../quality-assurance/content.md), then performs independent checks
before it can enter a message unit or approval relay. Missing shared QA blocks
acceptance. No local shortening, claim removal, stronger urgency or humanizer:
defects go to the same Writer under the contract's bounded corrective releases.

Creator owns images/video/audio and returns its quality evidence and actual
assets. Pass purpose and production constraints, not fabricated provider limits.
Separate generation budget, asset rights, remote-analysis/upload consent and
approval of the actual output. A media receipt does not prove it suits this
message; Marketer inspects relevance and remaining limitations. Do not route
directly to Creator's hands or duplicate its production measurements.

Researcher provides sources/claim checks, Engineer technical verification or
implementation. Scope the question and evidence needed; do not dispatch a
campaign as an unlimited research sweep. Keep facts, interpretation and unknowns
separate. Analysis reports are decision inputs, not new publication manuscripts.
