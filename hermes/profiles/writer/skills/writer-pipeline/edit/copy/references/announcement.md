# Editing a promotional announcement

Preserve the approved news, target audience and current/planned/conditional
status. A request to sound confident must not change a proposed launch into
an available product or remove a qualification on a benefit.

Edit only the released scope. Do not turn an awareness announcement into a
purchase pitch, add an action where none was requested, or manufacture proof
and urgency. Material changes to dates, terms or claims need source support.

## Craft decisions

Within authorized changes, clarify what changed, who is affected and the
consequence without upgrading planned status. Include when only if supplied.
If the lead repeats generic excitement, shorten that repetition only within
scope; do not replace it with invented adoption figures or a launch reason.
Protect intent: an awareness announcement can have no CTA or optional next step.
If the existing news is already clear, a no-op preserves the author's emphasis.
A request for confidence does not authorize a firmer date or broader audience.

## Worked example

Fictional material: an awareness draft says 「予約カレンダーに週表示が加わる予定と
なっております。」 Its protected body is 「Team プラン向けです。公開日は未定です。」
The brief confirms planned weekly display only for Team, with no release date;
the request authorizes shortening the opening while keeping its status.
Revision opening: 「予約カレンダーに週表示が加わる予定です。」
Why: the edit removes the extended ending, not the planned qualification.
The complete revision retains the protected audience and undecided date verbatim.
No next step is added because the purpose remains awareness, not registration.

Retain: if the opening already has this wording, return a no-op.
Counterexample: 「本日、週表示を公開しました。今すぐ登録を。」 invents timing,
changes planned to current availability and adds an unauthorized CTA.

QA evidence: compare the before/after status verb, approved audience and any
supplied timing; quote protected conditions. Explain absence of action through
the awareness purpose, not through a claim that all announcements avoid CTAs.

QA: compare the complete revision against the original and evidence, including
untouched conditions and action targets. Missing evidence remains explicit;
clarity is not proof of factual truth, legal approval or a successful launch.
Deliver a revised draft, never a changed live announcement.
