# Editing a proposal

Preserve the question to be decided, the requester's actual position, option
boundaries and known trade-offs. An open comparison must not become a chosen
plan just because a conclusion-first style was requested.

Keep estimates, assumptions and commitments distinct. New rankings, budgets,
deadlines or implementation stages need authorization and supporting material.
Use the same comparison criteria after reorganizing alternatives.

QA: the proposal asks for the same decision within the released edit scope.
Changes to the conclusion match an explicit request; stylistic confidence
does not create approval, a guarantee or an unrecorded preference.
