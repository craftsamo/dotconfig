# Editing Instagram Captions

Keep the caption bound to the supplied feed/reel media. Changing text does
not change image lettering, an alternative-text field or a video's narration.
Those are different inputs and must not be silently rewritten as part of this edit.

Preserve existing mentions, tags and intended reader action unless they
are in scope. A warmer tone does not justify a new testimonial, personal
experience, offer or claim about the audience's response.

Use plain text and deliberate line breaks. Do not insert Markdown markup
expecting it to render, or promise that a caption URL is universally clickable.
Current limits and publishing capability must be checked by the publishing
owner. Save a new draft version and obtain a fresh approval before publication.

Official reference (documentary check 2026-09-08, not an app test):
- https://www.facebook.com/help/instagram/442418472487929

## Craft Decisions

Edit the caption's relationship to its supplied image/carousel, not the unseen
image itself. If a key caveat appears only visually, bring it into authorized
caption text using supplied evidence; never invent details to make a connection.
Keep alt text separate and change it only if included in scope, based on
inspected content or explicitly attributed descriptions, not inferred emotion.
Retain useful voice and concise passages; a no-op is valid. Do not add a CTA,
personal experience or algorithm/growth promise to make the caption warmer.

## Worked Example (Fictional, MATERIAL-COMPLETE)

Supplied material: fictional C10 mapped to I10; fictional inspection record:
a ramp leads to an entrance beside a sign reading "Ground floor only".
Approved brief: the ramp serves ground floor only; upper floors require stairs.
Only caption clarity is editable; mapping and alt are protected. No CTA requested.
Creative-fiction allowance: this access notice, not additional facilities.
Original C10: "The entrance ramp provides access. See the sign for restrictions."
Original I10 alt: Ramp leading to the entrance beside a sign reading "Ground floor only".
Revised caption body:
```text
The entrance ramp provides access to the ground floor only.
Upper floors still require stairs.
```
Rationale: naming the restriction removes dependency on reading the sign;
it neither rewrites the image nor hides a material limit in alt alone.
Retain: I10 alt/mapping stay unchanged; keep captions that already state this scope.
Counterexample: "Step-free access throughout" changes the approved claim;
adding a lift or cheerful visitors invents information absent from the record.
QA: compare caption old/new to brief; confirm protected alt/mapping unchanged.
The fictional inspection record is not an actual inspection by this edit;
real visual verification, platform fit and audience response remain unverified.
