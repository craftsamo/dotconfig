# Editing Instagram Captions

Keep the caption bound to the supplied feed/reel media. Changing text does
not change image lettering, an alternative-text field or a video's narration.
Those are different inputs and must not be silently rewritten as part of this edit.

Preserve existing mentions, tags and intended reader action unless they
are in scope. A warmer tone does not justify a new testimonial, personal
experience, offer or claim about the audience's response.

Use plain text and deliberate line breaks. Do not insert Markdown markup
expecting it to render, or promise that a caption URL is universally clickable.
Current limits and publishing capability must be checked by the publishing
owner. Save a new draft version and obtain a fresh approval before publication.
