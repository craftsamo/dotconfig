# Slide script

Bind each unit to the actual slide/page ID. Separate on-screen wording from
speaker narration and staging notes; the presenter need not read the visible
text word for word. A written slide outline with no production speech contract
belongs to Document rather than this format.

Preserve factual claims, chart definitions and any supplied slide order. Spoken
bridges must not imply unseen evidence or add a recommendation the brief never
approved. No fixed number of points per slide or universal speaking-rate rule.

QA: narration and on-screen text agree, page mappings are unambiguous and notes
cannot leak into rendered/spoken text. This is not an implemented deck; layout,
live timing and presentation performance require evidence from the producer.

## Craft Decisions

Use the visible message to orient the audience and speech to explain its
meaning, evidence or qualification. Do not mechanically read every label/number.
If "as you can see" carries the only chart relationship, name the compared
measure, direction and relevant scope orally so the listener can follow it.
Keep needed caveats in audience-facing words, not solely in presenter notes.
Choose a spoken bridge only when the supplied next slide warrants it; no
forced slide count, conclusion-first order or time-per-slide prescription.

## Worked Example (Fictional, MATERIAL-COMPLETE)

Supplied material: slide SL10 is a fictional branch survey. Visible message:
"Shorter waits in the sample"; chart shows median wait, April 8 minutes and
May 5 minutes at East branch only. The brief says the cause is unknown.
A neutral presenter must explain the relationship; no next slide is supplied.
Creative-fiction allowance: presentation wording, not extra data or causes.
Draft, mapped to SL10:
```text
Visible: Shorter waits in the sample
Spoken: In this East branch sample, the median wait fell from eight minutes
in April to five in May. The survey does not establish why.
Notes: Chart values and month labels stay with the supplied slide.
```
Rationale: speech supplies the meaningful comparison and its evidential limit;
it does not read all chart furniture or imply a service-wide improvement.
Retain: the short visible message works with the spoken scope; do not expand
it into the whole paragraph merely to eliminate all division of roles.
Counterexample: "This proves the new system works" invents a system and cause.
QA: compare SL10's spoken measure/months/values/scope with the supplied chart
and quote the cause caveat. Notes are not speech; raw exports must match only
the spoken words. Duration and rendered readability remain unverified.
