# Comparison

Choose comparison criteria from the reader's purpose and supplied scope.
Use the same definitions, versions and conditions for each option where
possible; explicitly state non-comparable measurements or missing evidence.

Explain trade-offs without manufacturing a winner. A table may help lookup,
but should not flatten a decisive limitation into a small footnote. Preserve
the source's conditions when summarizing results. Do not invent scores to
fill a symmetric table or imply hands-on testing that did not occur.

QA: conclusions follow from comparable evidence and the stated priorities;
an absent measurement is unknown, not a zero or a disadvantage by default.

## Build a Fair Comparison

If the reader needs to choose, select the same axes for every option from
that decision: cost for the same period, behavior on the same workload, or
support in the named versions. Keep comparable conditions beside the values.
Give a decisive trade-off more explanation, not a predetermined winner or
equal-length praise for every product. Missing evidence may prevent a choice.

Locally authored example (hypothetical supplied measurements):
"On the same 100-file workload and machine, A finished in 8 seconds and B in
12 seconds. Memory use was not recorded."
Bounded conclusion: "A was quicker in this run; this evidence does not settle
which option fits a memory-constrained machine."
Reason: the speed axis has shared conditions, while the unmeasured axis is
still unknown. These invented teaching values are not reusable product facts.
Counterexample: comparing A's small-file run with B's large-file run cannot
support the same speed conclusion, even if both numbers are accurately quoted.

Retain: a table with genuinely parallel axes, useful qualifications and unknown
cells. Do not turn it into causal prose or replace unknown with a low rating.
An expert comparison can keep shared technical terms without redefining each
one; explain only distinctions that affect interpretation of an axis.

QA evidence: cite the source for each consequential cell and state the shared
conditions or mismatch. Read the conclusion against those cells and the stated
reader priority. Preserve a source's caveat in the heading as well as the body;
"faster in this run" must not become "the fastest option."
