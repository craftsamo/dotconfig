Connect the caption to supplied media without repeating everything already
visible or inventing what an unavailable image shows. Describe the source
of visual information honestly: inspected file or caller description.
An optional call to action must name an action the audience can actually
take; an unknown link surface is not a verified conversion path.

Do not fill a hashtag quota or add emoji because the platform is Instagram.
Check the current destination/account limits before publishing. Writer
creates text, not media, and this reference does not establish that the
Marketer has an Instagram publishing integration. Without one, draft-only.

## Craft Decisions

Connect the caption to the supplied image/carousel's point without reciting
every visual detail. If a claim needs a key caveat, state it in caption text,
not exclusively in image lettering, color or emoji that a reader may miss.
For requested alt text, describe meaningful inspected content, not unseen
details or inferred emotions; attribute a supplied description as such.
An action must name its real destination if requested. No hashtag quota,
algorithm/growth promise or personal experience is required for a useful caption.

## Worked Example (Fictional, MATERIAL-COMPLETE)

Supplied material: caption C10 and alt text for fictional image I10. A fictional
inspection record describes a ramp leading to an entrance beside a sign reading
"Ground floor only". Approved brief: the ramp serves only the ground floor;
upper floors require stairs. Voice is welcoming but factual; no action requested.
Creative-fiction allowance: this scenario's wording, not more access facilities.
Draft, with caption and separate alt field:
```text
C10 caption: The entrance ramp provides access to the ground floor only.
Upper floors still require stairs.
I10 alt: Ramp leading to the entrance beside a sign reading "Ground floor only".
```
Rationale: the caption explains the ramp's practical scope; alt conveys the
supplied visible content. Neither leaves the access restriction only in the image.
Retain: "only" and the stairs sentence are essential qualifications, not a
negative tone to soften away. Not every caption needs a hook or next step.
Counterexample: "Everyone can explore every floor" contradicts the material;
adding trees, smiles or a lift to alt text invents unseen details.
QA: map C10 to I10; compare caveat to brief and alt to the fictional inspection record.
This text is not an actual image inspection; unseen media limits alt verification.
