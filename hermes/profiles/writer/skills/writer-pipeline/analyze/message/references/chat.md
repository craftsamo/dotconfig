# Analyzing a chat message

Explain the words and their possible contextual reading. Flag missing context
when pronouns, shorthand or timing change the interpretation; do not recover
an imaginary conversation or resolve a sender through private records.

State what is explicitly expressed separately from possible emotional tone or
implied expectations. A short answer alone does not prove anger, rejection or
intimacy. A description need not propose a better response.

## Craft decisions

Ask whether the text forms one contextual unit the recipient can understand
and, if requested, act on. If previous referents compete, quote the shorthand
and name the competing topics only from supplied turns, not imagined history.
For a review, connect quote, evidence, mismatch and possible consequence; missing
context can leave ambiguity unresolved rather than establish a wrong answer.
A short informative reply needs no demand or greeting. Description can explain
that fit without a defect; analysis must not supply a replacement response.

## Worked example

Fictional material: prior turn 「会場は第2会議室、開始は15時でよいですか。」;
reply 「それで決まりました。」 The supplied intent confirms only the room, not
the time. The requester asks whether the reply communicates that limited decision.
Finding: quote 「それで決まりました」 against the two topics in the prior turn.
Mismatch: the reply does not identify the venue-only scope supplied by the sender.
Consequence: a reader could take it as confirmation of both room and start time.
Why: the analysis identifies the referent problem and evidence boundary rather
than claiming the recipient actually misunderstood or composing a clearer reply.

Retain: if the preceding turn instead names only one venue, this short answer
can be adequate; no greeting or extra request is needed to make it polite.
Counterexample: saying 「それ」 definitely means the time chooses a referent that
the wording does not establish, even though the supplied intent is venue-only.

QA evidence: include the minimum relevant turns, state the intended scope and
show which interpretation the words permit. Where context is missing, label the
limit instead of inventing earlier messages or claiming the sender is angry.

Comparisons use both supplied messages. The report does not draft a response,
