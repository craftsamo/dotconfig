# Analyzing promotional announcements

Identify the news, audience, status, benefit claims and action if present.
Use the actual request to distinguish description from evaluation. An
announcement with an awareness-only purpose need not contain a CTA.

Compare dates, current/planned wording and qualifications with supplied
evidence when factual checking is requested. An unprovided source is not proof
that a launch or claim is false; a confident statement is not proof it is true.
Reader excitement, coverage and commercial impact need their own evidence.

QA: observations answer the question and point to the relevant words. A
comparison reads both announcements. Recommendations stay recommendations;
the report neither replaces the original nor certifies publication or impact.
