# Analyzing promotional announcements

Identify the news, audience, status, benefit claims and action if present.
Use the actual request to distinguish description from evaluation. An
announcement with an awareness-only purpose need not contain a CTA.

Compare dates, current/planned wording and qualifications with supplied
evidence when factual checking is requested. An unprovided source is not proof
that a launch or claim is false; a confident statement is not proof it is true.
Reader excitement, coverage and commercial impact need their own evidence.

## Craft decisions

Trace what changed, who is affected, when only if supplied, and the supported
consequence. Distinguish planned from current availability in every field.
For review, quote the news/status, compare evidence, identify a mismatch and
explain its possible consequence. An unspecified date is not a missed deadline.
If the purpose is awareness, absence of a CTA is valid; an optional next step
needs support only when present or required. Do not turn description into a
replacement announcement or invent audience excitement to justify criticism.

## Worked example

Fictional material: headline 「週表示を公開しました」; body 「Team プラン向けです。」
The approved awareness brief says weekly calendar display is planned only for
Team, with no release date decided. The requester asks whether status is faithful.
Finding: quote 「公開しました」 against the brief's planned status and undecided date.
Mismatch: the headline presents a future capability as already available.
Consequence: a Team member could look for the feature now, although the supplied
material does not establish availability. The absence of a CTA is not a problem.
Why: the report identifies the consequential status change without inventing
a launch date, asserting actual user frustration or supplying replacement copy.

Retain: 「Team プラン向けです。」 matches the approved audience; retain that
positive observation rather than treating the whole announcement as defective.
Counterexample: demanding a signup link for this awareness brief changes the
purpose, while saying the launch definitely failed exceeds the status evidence.

QA evidence: preserve the quoted status and compared brief, explain the bounded
consequence, and distinguish missing timing from contradictory timing. Note
purpose fit for an absent action without making no-CTA a universal rule.
