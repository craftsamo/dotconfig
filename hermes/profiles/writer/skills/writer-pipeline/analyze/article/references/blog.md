# Analyzing Blog Source

Judge the stated question and actual text, not a universal blog skeleton.
When comparing articles, account for their different readers and purposes
instead of ranking one as universally better.

An unspecified CMS provides no rendering contract. Distinguish ordinary
Markdown intent from engine-specific tables, footnotes, HTML, embeds or image
features. A source file and a live page are different evidence; report which
was read. Do not infer visual quality, accessibility compliance, working code
or publication success from source text alone.
