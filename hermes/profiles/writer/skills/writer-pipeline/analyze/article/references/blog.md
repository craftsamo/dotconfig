# Analyzing Blog Source

Judge the stated question and actual text, not a universal blog skeleton.
When comparing articles, account for their different readers and purposes
instead of ranking one as universally better.

An unspecified CMS provides no rendering contract. Distinguish ordinary
Markdown intent from engine-specific tables, footnotes, HTML, embeds or image
features. A source file and a live page are different evidence; report which
was read. Do not infer visual quality, accessibility compliance, working code
or publication success from source text alone.

## Locate the Reader's Difficulty

If the question concerns explanation quality, trace the reader's question
through headings and paragraph openings to the actual answer. Inspect the
full passage before judging a missing dependency. Unknown audience knowledge
or house notation limits the finding; preserve supplied usage rather than
declaring a different convention correct for every blog.

Locally authored example (analysis of a hypothetical excerpt):
Quote: "The replica uses eventual consistency." The supplied brief names
first-time database users; the section gives no account of delayed updates.
Finding: the two unexplained terms require prior knowledge the brief does
not establish. Reader impact: the passage names the mechanism without helping
the reader understand why two copies can differ. Recommend explaining that
relationship, not a replacement paragraph or an invented system guarantee.
If the audience is unknown, make the novice-reading concern conditional.

Retain: the same concise sentence for a known expert audience, a short label
heading whose purpose is obvious, or independent bullets useful for lookup.
Description mode may explain these choices without finding defects. Uneven
section depth is useful when it reflects the reader's actual difficult point.
Repeated phrasing alone is neither an error nor an authorship signal.

QA evidence: attach the quote, relevant reader criterion and inference to
each substantive finding. Distinguish a textual omission from missing external
evidence, and note what would change the assessment. Keep article and notes
unchanged; report no replacement article. A source reading establishes neither
CMS support nor live readability, and does not need a numeric quality verdict.
