# Analyzing storyboard text

Anchor sequence, action and transition observations to actual shot IDs and
fields. Separate stated timing and camera intentions from evidence that a
rendered sequence performs them. Read supplied reference material only for the
aspects the question actually asks about.

Compare exact-text boundaries and producer fields when assessing usability.
No tool is assumed to accept a multi-shot script merely because it can generate
one clip. Missing footage cannot be replaced with an imagined viewing verdict.

QA: conclusions reflect the inspected text and known production contract.
An analysis is not a new storyboard, rendered frames or permission to edit
the source sequence, create media or certify continuity in an unseen video.
