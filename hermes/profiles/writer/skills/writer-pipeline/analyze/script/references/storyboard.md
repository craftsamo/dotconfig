# Analyzing storyboard text

Anchor sequence, action and transition observations to actual shot IDs and
fields. Separate stated timing and camera intentions from evidence that a
rendered sequence performs them. Read supplied reference material only for the
aspects the question actually asks about.

Compare exact-text boundaries and producer fields when assessing usability.
No tool is assumed to accept a multi-shot script merely because it can generate
one clip. Missing footage cannot be replaced with an imagined viewing verdict.

QA: conclusions reflect the inspected text and known production contract.
An analysis is not a new storyboard, rendered frames or permission to edit
the source sequence, create media or certify continuity in an unseen video.

## Craft Decisions

Trace each stable ID's intended visual, spoken information and transition
cause. If a result lacks its setup, quote the adjacent fields and explain the
missing relationship rather than inventing a new shot to connect them.
Check crucial visual information against required speech/descriptive-plan
coverage, including meaningful sound sources and speaker identity when present.
Give findings without replacement units; accessibility planning is not a
renderer contract, caption-file task or proof of actual transition execution.

## Worked Example (Fictional, MATERIAL-COMPLETE)

Supplied material: fictional S10 shows a hand pressing a switch; S20 shows the
lamp it turns on. Neutral narration must convey the result without sight.
The supplied transition follows that switch's effect to S20, then ends. No
sound, descriptive plan or footage is supplied. Review essential information.
Creative-fiction allowance: this demo's actions, not new device capabilities.
Supplied draft:
```text
S10 | Visual: A hand presses the switch. | Narration: This switch turns on the lamp.
S10 | Transition: Follow the switch's effect to the lamp in S20.
S20 | Visual: The lamp lights. | Narration: Now this happens. | Transition: End.
```
Finding: S20's "Now this happens" leaves the actual result in the visual field.
Evidence: S10 explains the switch's function but S20 never names the observed
state in speech. Consequence: a listener can infer, but cannot confirm, success.
Rationale: causal sequence and nonvisual result coverage are separate textual criteria.
Retain: S10's transition identifies why S20 follows; no new camera move is needed.
Counterexample: if an approved descriptive plan conveys S20's result, silence
can be appropriate; speech in every unit is not a universal requirement.
QA: cite both IDs/fields and the audience requirement; source stays unchanged.
Duration, actual transition and produced accessibility remain unverified.
