# Analyzing narration

Quote the words supporting observations about explanation, voice or flow.
For consumer-fit questions, check whether the intended speech file contains
only spoken words and whether supplied notes/exports agree with the master.
Missing files limit only conclusions that need them.

Distinguish the reader's interpretation of text from an actual voice performance.
No listening, pronunciation, synthesis or exact-duration claim follows from
punctuation or character count alone. Existing timing needs a matching version.

QA: observations answer the question and identify the relevant text. The report
needs no replacement narration or raw speech export, and cannot authorize a
take, script rewrite, subtitle update or voice selection.
