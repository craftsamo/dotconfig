# Analyzing narration

Quote the words supporting observations about explanation, voice or flow.
For consumer-fit questions, check whether the intended speech file contains
only spoken words and whether supplied notes/exports agree with the master.
Missing files limit only conclusions that need them.

Distinguish the reader's interpretation of text from an actual voice performance.
No listening, pronunciation, synthesis or exact-duration claim follows from
punctuation or character count alone. Existing timing needs a matching version.

QA: observations answer the question and identify the relevant text. The report
needs no replacement narration or raw speech export, and cannot authorize a
take, script rewrite, subtitle update or voice selection.

## Craft Decisions

Trace audible order: does a pronoun have a named object before it, or does
understanding require a picture? Quote the missing/competing referents rather
than guessing the intended object. For nested qualifications, identify which
action each condition constrains and the consequence of ambiguous attachment.
Report effective orientation and pacing as well as defects. Text inspection
does not establish a read-aloud result; give findings without replacement words.

## Worked Example (Fictional, MATERIAL-COMPLETE)

Supplied material: fictional tutorial N10; a blue return box accepts books
borrowed at this branch only, and insertion requires its lid to be open.
Voice is calm and direct. No image, raw export, notes or timing evidence is
available. Review question: can a listener identify the action and conditions?
Creative-fiction allowance: the tutorial's scenario, not real library policy.
Supplied draft N10:
```text
When it is open, put books borrowed at this branch only here.
```
Finding: N10's "it" and "here" have no named object in the supplied speech.
Evidence: the material identifies the blue return box and its lid; the line
names neither. Consequence: a listener must infer both the destination and
what must be open. The words retain branch eligibility but not a clear action.
Rationale: report this referent gap, not a replacement narration or extra unit.
Retain: "borrowed at this branch only" accurately limits the eligible books;
its length is not itself a defect. Useful orientation should not be cut by rule.
Counterexample: if earlier inspected speech named the box and lid, the pronoun
could work; check that context before reporting the same finding elsewhere.
QA: anchor the finding to N10 and its exact quotes. Export equality is
unverified because no export was supplied; do not treat the report as one.
Duration, pronunciation and read-aloud performance remain unverified; source unchanged.
