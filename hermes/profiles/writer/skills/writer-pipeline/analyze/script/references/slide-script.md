# Analyzing slide scripts

Read the mapped page IDs and separate visible text, spoken narration and notes.
Explain alignment, repetition or transitions using the actual fields. If slides
are unavailable, limit observations about their visible appearance rather than
pretending the script proves the rendered layout.

Check factual qualifications across visible/spoken text where evidence permits.
Page count or an intended speaking rate does not establish actual talk duration.
Compare both versions when requested without editing the deck or the script.

QA: findings identify the relevant page/field, distinguish observation from
interpretation and answer the question. The report needs no new slides, speaker
notes or narration payload and is not approval to render or present.
