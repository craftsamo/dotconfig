# Analyzing slide scripts

Read the mapped page IDs and separate visible text, spoken narration and notes.
Explain alignment, repetition or transitions using the actual fields. If slides
are unavailable, limit observations about their visible appearance rather than
pretending the script proves the rendered layout.

Check factual qualifications across visible/spoken text where evidence permits.
Page count or an intended speaking rate does not establish actual talk duration.
Compare both versions when requested without editing the deck or the script.

QA: findings identify the relevant page/field, distinguish observation from
interpretation and answer the question. The report needs no new slides, speaker
notes or narration payload and is not approval to render or present.

## Craft Decisions

Inspect the division between visible message, spoken explanation and notes.
If a chart relationship exists only in the visual field, name the information
missing from speech and its consequence for a listener without the slide.
Do not demand every label/number aloud: identify the meaningful comparison,
scope and caveat needed for this purpose. A presentation may use deliberate
repetition; assess its function rather than enforcing a fixed slide/time count.
Give findings without replacement narration or changes to the mapped slide IDs.

## Worked Example (Fictional, MATERIAL-COMPLETE)

Supplied material: fictional SL10, "Shorter waits in the sample", charts East branch
median wait: April 8 minutes, May 5 minutes. Cause unknown. A neutral presenter must
explain the relationship without sight. Only script/chart data, no rendered deck.
Creative-fiction allowance: these sample data, not a real survey or new causes.
Supplied draft:
```text
SL10 | Visible: Shorter waits in the sample
SL10 | Spoken: As you can see, it fell. We do not know why.
SL10 | Notes: Chart shows East branch only, April 8 minutes, May 5 minutes.
```
Finding: SL10's "it fell" does not name the measure or comparison in speech.
Evidence: branch/month/value information exists only in chart material and
notes. Consequence: a listener without the chart cannot identify what changed.
Rationale: this is missing spoken explanation, not a request to read all labels.
Retain: "We do not know why" accurately preserves the unknown cause; the
visible message is not defective simply because it is shorter than narration.
Counterexample: if earlier supplied speech establishes the same comparison,
brief reference may suffice. Do not infer such context from an unseen slide.
QA: quote SL10's fields against the audience requirement; source and IDs unchanged.
Duration/rendered readability are unverified, not failed. No new notes or payload.
