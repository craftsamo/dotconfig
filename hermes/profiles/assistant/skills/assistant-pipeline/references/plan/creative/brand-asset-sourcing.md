# Brand asset sourcing — decision surface

Official third-party logos/marks, sourced with provenance — never
redrawn, traced, or generated. The user's OWN brand assets: ask
them for the file. First-party icon derivation → `logo-icons.md`.

Technic `creator-brand-asset-sourcing` · QA `sourced-asset` ·
retrieval, zero generation spend · card: `deterministic-render`
does NOT apply — resident-only (judgment per vendor).

## Fix before release

- The mark list: which companies/products, and for each the
  destination background (light-ink vs dark-ink variant) and
  **glyph-only logomark vs full lockup** — they have different
  aspect ratios; the layout decides.
- The fallback policy: when a vendor publishes no official file,
  the deliverable falls back to a text wordmark in the
  deliverable's own typography — sanction that fallback (or the
  stop-and-ask) here.
- Usage context for the rights record: the report carries each
  vendor's terms (nominative use, no-modification clauses);
  commercial shipping contexts need the user to see them.

## Defaults

- Anchor: none.
- Budget shape: zero spend. Unmodified bytes are an invariant —
  recolor/crop requests against "as provided" terms come back to
  you as findings, not silent edits.
