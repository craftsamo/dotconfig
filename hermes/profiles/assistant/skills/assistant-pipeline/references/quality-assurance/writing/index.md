# Writing QA contracts — routes

Read the actual file, whole — never judge from the reply summary. The
common floor in `../index.md` always applies.

| Deliverable family | Contract |
| --- | --- |
| Prose (copy, article, documentation) | `prose.md` |
| Script / storyboard / screenplay | `script.md` |

Beyond the contract files:

- Check against the brief: type, audience fit, tone, length, language,
  required facts present and correct (spot-check claims against the
  pasted sources).
- Japanese deliverables: notation consistency (表記ゆれ), register
  stability, no LLM-smell filler; scripts additionally: the downstream
  producer's field/unit conventions are honored exactly.
