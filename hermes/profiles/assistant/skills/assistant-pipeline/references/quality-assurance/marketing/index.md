# Marketing QA — pre-publish and post-publish

Publishing is irreversible; this gate runs before any relay/approval and
again after any post. The common floor in `../index.md` always applies.

Before relay/approval:

- Copy matches the brief and brand voice; claims are true (check against
  sources).
- Attached media passed the creative contracts (`../creative/index.md`).
- Links resolve; platform constraints (length, media specs) hold.
- The text you relay to the user is **verbatim** what would ship.

After posting:

- The reported URL is live and matches the approved content exactly.
- For `P1` runs, spot-check the first post immediately.
