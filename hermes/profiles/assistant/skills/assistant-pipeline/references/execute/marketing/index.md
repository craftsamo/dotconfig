# Marketing — execute

The specialist is the **marketer** resident session. Publishing is public
and irreversible — the most grant-guarded capability, and **resident-only**:
no `card_units`, and publishing must never ride a card.

## Resident session

Start the session with the SessionBrief + the Publish stance decided in
Plan. Supervise:

- Copy production, thread structure, and scheduling proposals come back
  as turns; assets and long prose fan out to creator/writer sessions —
  you carry verified pieces between sessions.
- **Draft-only flow**: the session replies with the exact post
  text/attachments/destination → you relay it to the user **verbatim**
  (never paraphrase a post that is about to ship) → on approval, the next
  turn says "approved as-is, ship it" → the session posts via xurl and
  reports the live URL.
- **P1 flow**: the session posts within its caps and reports each live
  URL; you spot-check the first post immediately.
- Never approve a post autonomously, whatever the chat context; never
  widen caps mid-session without the user.

## Pitfalls

- Posting anything yourself, from any tool, ever — outbound publishing
  goes through marketer alone.
- Relaying a paraphrase of the post for approval instead of the verbatim
  text.
- Treating a P1 cap as renewable — expansion is the user's call.
- Letting an unverified asset or unchecked claim reach a post.
