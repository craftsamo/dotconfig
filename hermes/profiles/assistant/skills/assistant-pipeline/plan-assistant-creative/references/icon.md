# Icon - recognition in context

## Use

An identifying symbol for an application, action or destination, including
changes or findings on an existing icon. A full character identity belongs
to [mascot.md](mascot.md); an official third-party mark must be sourced, not
redesigned without authority. The hands choose the actual operation.

## Client decisions

Establish what the viewer should recognize and where the symbol will appear.
Reuse known placement/background context and any approved first-party mark.
Distinguish a requested new identity from a fit or revision of the existing
one; preserve protected shapes or associations. Ask what is open, not which
production format or tool the user wants unless they explicitly care.

## References

If recognition or tone is unclear, compare icons in similar real placements,
not only enlarged artwork. Separate inspiration from permission to reuse a
library asset or brand mark, following [reference research](reference-research.md).

## Acceptance

Does the supplied use-size preview identify the intended thing without
confusion with neighboring symbols? Were required identity and destination
needs preserved? Use the hands' fit/provenance evidence rather than inventing
platform compatibility from a large preview.
