# Manim explainer — decision surface

Legacy only: use after Creator confirms this method, per [index](index.md).
Never use it as a fallback for a served failure or unsupported field.

Educational animation: concept, equation, algorithm, data, paper,
and 3D modes. Correctness is the point — this family carries an
evidence requirement like research work.

Technic `creator-manim-explainer` · QA `video` (+ claim evidence) ·
deterministic Manim render, zero generation spend (narration is a
separate Creator brief for audio-creator's `generate-speech`,
approved script required) · resident-only.

## Fix before release

- The lesson: objective, audience level, notation conventions — and
  the **source of truth** for every mathematical/algorithmic claim
  (paper, textbook, verified derivation); the creator renders
  claims, it does not establish them.
- Scene order, what each scene must show, and pacing appropriate to the
  agreed learning goal; no fixed visual style or dramatic intensity.
- Narration/subtitles: script (writer work, QA-passed) and timing
  alignment; subtitle language(s).
- Delivery contract: resolution, aspect, duration, codec.

## Defaults

- Anchor: a `-ql` draft of the first scene approved before the
  full-quality render run.
- Budget shape: zero generation; LaTeX/render iterations are turns.
  Equation/label readback at delivery size is the acceptance floor.
