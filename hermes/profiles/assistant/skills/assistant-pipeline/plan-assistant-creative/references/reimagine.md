# Reimagine - change the expression, preserve the chosen subject

## Use

A supplied photo interpreted in a different visual medium or setting while
preserving specified traits. A reaction pack is [emoji.md](emoji.md), and a
new reusable identity is [mascot.md](mascot.md). Ask Creator whether the
requested transformation is supported instead of treating all edits as alike.

## Client decisions

Identify the original photo, what must stay recognizable and what may change:
identity, pose, composition or context. Keep the original unchanged. Distinguish
an artistic direction from a request for factual restoration. Confirm any
necessary reuse and upload permission explicitly; a supplied personal photo
or selected style alone does not authorize sending it to a production model.

## References

Use [reference research](reference-research.md) only if a comparison helps
choose the medium or degree of change. Explain which traits of the example
are relevant rather than turning the entire found image into a model input.

## Acceptance

Compare the original with the result for the user's stated invariants and
the agreed degree of reinterpretation. A pleasing image that changes the
protected identity is not a successful result. Report uncertainty where
the hands' evidence cannot establish preservation.
