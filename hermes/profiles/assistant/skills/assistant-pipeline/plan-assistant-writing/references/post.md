# Social Post Text

Writer type `post` · QA `prose` · one post, ordered thread or caption per
released unit. X Articles are articles; private replies are not feed posts.

Read the selected Writer leaf's form: `write-post` for new text,
`edit-post` for scoped changes to existing text, `analyze-post` for a
description, review or comparison without rewriting. Do not treat analysis
as a publishable body. No source text yet means consultation,
not analysis of an imagined draft.

## Settle before release

- The message, audience, platform and format: X single/thread or Instagram
  feed/reel caption. Claims and offers come from the client's decisions.
- Grounding sources or fact-ledger entries, not style examples treated as
  evidence. Missing facts return to the evidence owner rather than Writer.
- Tone (including the positioning record's voice anchors and required/banned
  terms for marketing work), length target or hard constraint, exact handles/tags if required,
  action if any, protected wording and exclusions. Infer answered fields.
- Supplied media IDs/paths and their intended post IDs. Caption text does
  not create an image or authorize media generation. Missing required media
  is a separate dependency with an owner, not a silent placeholder deletion.
- Edit: original text, requested changes and protected IDs/order. Analyze:
  target, question and any comparison target or requested review criteria.
- `humanizer` only when explicitly requested; default off. Never request
  the old lint score or a four-pass receipt from these served leaves.

## Receive and hand off

Writer returns the complete draft at the released destination and reports
its leaf, post IDs, media mapping and applicable criterion evidence as
checked / unmet / unverified. A short analysis may be returned in the reply;
it is findings, not a new post. Required unverified constraints remain open.

Read the actual artifact under the writing QA gate, then use accepted text
and media as parts of the marketing job. Marketing Execute checks actual
platform fit, facts and legal constraints (Marketer's review is advice on
these) and obtains exact-content remote-save approval. It saves service drafts
only; the user publishes.
A Writer draft or an A2A reply grants no publication authority.
Text defects return to Writer; consumers never rewrite the body themselves.
Instagram publication remains unavailable unless a real authorized route
exists; do not infer an integration from a caption-writing capability.
