# Video craft reading

Knowledge-only craft is distinct from the optional HyperFrames technical policy.
It does not import another renderer, script, agent, approval gate or style menu.
The selected leaf remains authoritative for controls, media and production.

Before a temporal design decision or perceptual review, read
`skill_view(name="media-craft-motion")`, then use its `file_path` for the relevant
files below. Do not load every file merely because the result is a video.

| Subject and decision | Motion reference files |
| --- | --- |
| clip generation and shot interpretation | `references/generated-shots.md`; `references/timing-spacing.md` for an actual motion choice |
| tour action, pointer, camera and UI state | `references/ui-choreography.md`, `references/timing-spacing.md`; `references/continuity.md` for state/scene connections |
| ad pacing, attention and scene relationships | `references/timing-spacing.md`, `references/continuity.md` |
| explainer-video causal state and supplied performance | `references/explanation-performance.md`; timing/continuity files when needed |
| music-video shots against supplied music | `references/generated-shots.md`, `references/continuity.md` |

Read `references/motion-review.md` before a perceptual review, including
analyze-ad and a creative analyze-clip request. Pure trim, re-encode, metadata or
frozen render-only resumes do not introduce a new motion decision.

For authored layout or visual treatment, also read
`skill_view(name="media-craft-visual")` and its `references/composition.md`,
`references/typography.md` for visible text, `references/systems-assets.md` for
UI relationships, or `references/surface-light.md` for material/light decisions.
These are conditional, not four required reads on every shot. No image generation
or reskinning of faithful UI is authorized by visual advice.

For a doubtful concept, read `skill_view(name="media-craft-direction")` and its
`references/critique-revision.md` or `references/reference-interpretation.md`.
Return direction changes/dependencies to Creator. No direct audio or image hands
calls, new music, inference of lip sync, or exact generative timing is implied.

Keep required bodies in current context. On missing-body/unchanged responses,
recover the canonical file under `~/.agents/skills/<skill>/` with `read_file` and
follow real truncation. Missing/ambiguous required craft stops the affected
creative action, not unrelated mechanical work; never install or silently reroute.
Optional HyperFrames references keep their own local-authoring fallback.

Record consulted skill/file, decision and frame/interval evidence in existing
`qa.md`. State actual image resolution and sampled versus normal-speed evidence.
Do not repeat the old all-frames claim for sparse sheets. Honor existing review
allowances, proposal/preview approvals and generation budgets. A study is not a
final release, and this reference creates no study capability by itself.
