# One Line

Intent: a calm, elegant explanation where each idea is drawn as a single
continuous line; suits concepts, stories of change and soft topics.

Material: warm off-white paper, generous empty space, no textures other
than a faint paper tone.

Ink: one dark, even-weight line draws each object without lifting (a
chair, a plant, a window), then a few flat pastel colour blobs slide in
slightly offset behind the line, never filling it exactly. Transitions
can let the line retract into its tip and draw the next object. Labels
are a thin, quiet sans placed in the empty space.

Best paired with `comparison`/`misconception` directions, where two
line drawings sit side by side. A custom, equally concrete free-text
style description is implemented verbatim, never coerced onto this
preset.

QA: the line looks continuous in sampled frames (no visible restarts
inside one object); stroke weight stays even; colour blobs stay offset
and soft; labels never cross the line.
