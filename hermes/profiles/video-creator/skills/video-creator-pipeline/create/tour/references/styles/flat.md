# Flat

Use for direct instructional walkthroughs. Solid dark label plates, modest
rounded frame, accent target border and no backdrop blur. The static
cover-fit backdrop has an 80% black scrim. Light/dark/hex remains the
underlying ground; without a backdrop it is not dimmed, and heading ink is
chosen by luminance. Verify source UI readability and authored-label contrast
from real rendered evidence; the style name is not a QA verdict.
