# Glass

Use for a softer backdrop treatment, not translucent screenshot content.
The static cover-fit backdrop alone gets 16 px blur and a 65% black scrim;
screenshots stay sharp, and label plates stay opaque for predictable text
contrast. No animated background, frosted text or cross-media palette.
Without a backdrop, the background stays undimmed with luminance-selected ink.
Review contrast samples and actual UI text rather than assuming glass passes.
