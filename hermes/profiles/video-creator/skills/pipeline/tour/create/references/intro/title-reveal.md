# Title Reveal

Role: state the task before revealing its UI. Default ON, not mandatory.
Appearance: one concise title in the presentation layer, then the same window
becomes the subject. Inputs: approved task title, initial UI and reading time.
Motion: title docks/scales into a heading while the UI rises or is unmasked;
keep the UI carrier continuous into the first action. No long empty logo sting.
QA: readable title, actual reveal transition, no title/control overlap, first
action begins only after the user can locate its target. Adapt geometry locally.
