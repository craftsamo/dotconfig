# UI Overview

Role: orient viewers already familiar with the task. Appearance: the whole UI
with a short heading. Inputs: initial state, heading and first focus target.
Motion: establish full context, bring the pointer toward the target, then push
and pan with intent. Preserve one window; do not cut to a different screenshot.
QA: full view is readable, focus has a visible cause, pointer contact stays
correct under zoom, heading does not hide controls. Timing is task-specific.
