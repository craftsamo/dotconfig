# Pixel

Medium: a pixel-art-styled animated shot, not a photograph with a mosaic filter.

Prompt block: <subject> represented by deliberate low-resolution pixel clusters,
a limited coherent palette, readable silhouette and restrained background.
Perform <motion> with clear discrete poses, fixed pixel scale and no smooth
vector edges. No blur, shimmering texture, changing grid, text or watermark.

QA cues: readable clusters rather than noisy pixel texture; grid/palette remain
visually stable across the shot. This model-generated aesthetic is NOT proof
of an exact sprite grid, palette or seamless loop. Those requests need the
deterministic pixel-animation path rather than this leaf.
