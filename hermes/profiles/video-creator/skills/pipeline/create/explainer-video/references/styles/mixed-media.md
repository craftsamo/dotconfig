# Mixed Media

Intent: combine a clean technical diagram with a more textured,
hand-annotated feel — useful when the topic benefits from both precision
(the mechanism itself) and warmth (a sense of someone explaining it to you).

Material: flat-vector diagram elements for the precise, labeled parts,
composited over a lightly textured backdrop (soft paper grain, subtle
canvas weave, or a muted photographic-feel gradient — never a busy
photograph that competes with labels).

Ink: the diagram itself stays flat and solid-filled; hand-drawn-feeling
annotation marks (a circled detail, an underline, a sketchy arrow) sit on
top in a single accent ink color, as if marked up after the fact. Keep the
two treatments visually distinct — never blend the diagram's own fills
into a textured/sketchy look.

Best paired with `worked-example`/`misconception` directions, where an
annotation mark needs to call out one specific detail against a clean
diagram. A custom, equally concrete free-text style description is
implemented verbatim, never coerced onto this preset.

QA: confirm the flat-vector diagram elements and the textured/hand-drawn
accents stay visually distinct in sampled frames, with no blending drift
between the two treatments.
