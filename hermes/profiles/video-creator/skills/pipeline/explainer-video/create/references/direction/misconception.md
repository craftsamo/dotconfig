# Misconception

Intent: directly address a common false belief before replacing it with
the correct explanation, so the correction actually lands.

Layout: the mistaken belief is shown first and explicitly marked as wrong
(a strikethrough, an X mark, a visibly "crossed out" treatment) — never
presented as if it were simply the first correct step. The corrected
explanation then occupies its own clearly separated hold, ideally reusing
the same composition so the contrast (what changed) is legible.

Affordance: the crossed-out state and the corrected state should be
visually comparable at a glance (same layout, same labeled part) so the
viewer sees exactly what was wrong and what replaced it, not two unrelated
scenes. Never let the wrong belief's visual be the last thing on screen —
the correction always gets the final, uncontested hold.

A custom direction may frame the misconception as a question first, but
must still mark it clearly wrong before the correction, never leave it
ambiguous which claim is endorsed.

QA: confirm the crossed-out (wrong) state and the corrected state each land
in their own sampled frame, and the correction's frame is the later one in
every sequence.
