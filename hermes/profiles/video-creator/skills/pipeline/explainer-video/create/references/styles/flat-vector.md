# Flat Vector

Intent: maximum clarity and legibility — the diagram reads instantly, with
nothing competing for attention against the labeled copy.

Material: geometric shapes with clean, even fills; no gradients, drop
shadows, textures or simulated lighting. Depth is implied only by simple
overlap/scale, never by shading.

Ink: solid, saturated fills bounded by a thin, consistent-weight outline
stroke (or no outline at all, if the fill contrast is already high). A
small, restrained accent palette (2-3 colors plus a neutral) carries
`copy`/callout emphasis; every other shape stays a quiet supporting color.
Line art (arrows, motion paths) uses the same stroke weight throughout the
scene.

Best paired with `mechanism`/`process`/`worked-example` directions, where
exact part shapes and motion paths need to stay unambiguous. A custom,
equally concrete free-text style description is implemented verbatim,
never coerced onto this preset.

QA: confirm every fill in sampled frames stays within the approved 2-3
color accent palette plus neutral, with no gradient/shadow drift introduced
partway through the render.
