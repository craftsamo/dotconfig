# Workbench

Intent: a hands-on, mechanical setting suited to topics about how a
physical object works — the viewer should feel close enough to see the
parts move.

Space: a workbench or worktable surface filling the lower frame, the
subject object (or a labeled cutaway/exploded view of it) resting at a
comfortable inspection distance, restrained tools relevant to `topic` at
the frame edge (never crowding the labeled area). Good pairing with the
`mechanism`/`process` directions, where cause-and-effect motion needs an
uncluttered stage.

Material: matte wood/metal/rubber-mat surfaces, a single overhead work
light with soft shadow, worn-but-clean tool textures. Avoid busy pegboard
patterns directly behind the labeled subject. A free-text `theme` overrides
any motif/palette/light choice here; an explicit client constraint always
wins over this default.

This is a decorative workshop backdrop, never a claim about a real brand,
tool or third-party product unless separately approved. A custom, equally
concrete free-text description is implemented verbatim, never coerced onto
this preset.

QA: confirm the subject object (or its cutaway) and at least one relevant
tool are both visibly on screen together in sampled frames, not only the
bare bench surface.
