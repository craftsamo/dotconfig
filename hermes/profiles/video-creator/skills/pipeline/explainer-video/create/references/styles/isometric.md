# Isometric

Intent: a tidy miniature world seen from above at an angle, where
systems, flows and places can be shown whole without perspective.

Material: blocks and props on a 30-degree isometric grid, each with a
light top face and two darker side faces of the same hue; soft ambient
occlusion at the base instead of cast shadows; a calm pale ground.

Ink: flat fills, no outlines or a single thin darker edge; a restrained
palette (2-3 hues plus neutrals); moving items (packets, balls, parcels)
in one bright accent travelling only along the grid axes. Labels float
on small flat tags that stay upright (never skewed with the grid).

Best paired with `process`/`mechanism` directions: pipelines, factories,
networks, cities. A custom, equally concrete free-text style description
is implemented verbatim, never coerced onto this preset.

QA: every object respects the same isometric angle (no stray perspective);
face shading keeps one light direction throughout; labels stay upright
and readable; moving items stay on grid axes.
