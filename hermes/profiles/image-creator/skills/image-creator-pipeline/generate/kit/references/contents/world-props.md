# world-props

Suggested starter objects; adapt descriptions to the agreed world, never
silently add these when `items` was supplied. Native canvas: 256x256;
pixel: 32x32. One common camera and ground-contact convention, no drawn
floor. These are 2D sprites, not scene meshes or collision geometry.

| item | description | state |
| --- | --- | --- |
| crate | closed supply crate with recognisable reinforced corners | static |
| barrel | storage barrel with two clear bands | static |
| chest | closed treasure chest, single front latch | static |
| torch | freestanding unlit torch prop, no animated fire | static |
