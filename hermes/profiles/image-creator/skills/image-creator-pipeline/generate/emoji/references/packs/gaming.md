# gaming — the voice-chat and lobby set (10)

For gaming servers: reactions that happen between matches. Props are
generic (a controller, a headset), never a real brand's device or logo.

| name | expression / pose / prop |
| --- | --- |
| gg | relaxed grin, one hand raised in a small wave, controller in the other |
| victory | both arms up, eyes shut in joy, tiny confetti |
| rage | red face, controller held over the head about to be thrown, steam puffs |
| focus | headset on, eyes narrowed at the screen, tongue tip out |
| levelup | proud chest-out pose, a small upward arrow and sparkles beside the head |
| loading | blank stare, a small spinning-circle motif beside the head |
| afk | face-down asleep on a keyboard, a drifting "z" bubble |
| niceshot | thumbs up, one eyebrow raised, impressed smirk |
| clutch | sweating hard, eyes wide, gripping the controller with both hands |
| salty | pouting, arms crossed, looking away |
