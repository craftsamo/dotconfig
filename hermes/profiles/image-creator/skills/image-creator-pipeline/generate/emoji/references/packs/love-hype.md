# love-hype — the encouragement set (10)

Cheering, thanking, celebrating. Warm and loud; props are big and simple
so they read at 32 px.

| name | expression / pose / prop |
| --- | --- |
| hearteyes | heart-shaped eyes, hands clasped under the chin |
| hug | arms open wide toward the viewer, beaming |
| thumbsup | confident grin, one big thumbs up filling the lower half |
| clap | hands mid-clap with small motion lines, happy |
| fire | excited face, small flames around the head |
| party | party hat, blowing a party horn, confetti |
| sparkle | eyes shut in bliss, sparkles all around |
| rocket | leaning forward as if launching, speed lines behind |
| cheer | pom-poms in both hands raised high, mouth open in a cheer |
| kiss | puckered lips, one eye closed, a small heart floating away |
