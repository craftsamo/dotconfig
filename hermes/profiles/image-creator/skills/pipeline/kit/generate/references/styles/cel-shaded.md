# cel-shaded

**Look.** Inked 2D game assets with a stable dark contour and two hard-edged
shade levels. Saturated accents are limited to the same palette roles.

**Prompt block.**
> Cel-shaded 2D game drawing of <item>, <palette>, bold consistent dark
> outline, two flat shadow tones, upper-left light, simple readable shape,
> <prop perspective or front-facing UI>, isolated on flat <key colour>,
> no gradient, no lettering, no watermark, no floor shadow.

**Avoid.** Soft airbrush gradients, photographic surfaces, variable stroke
weight between items, comic speech text, light moving between assets.

**QA cues.** Shadow boundaries are crisp, outlines scale with display size,
the object reads when reduced, and UI interior regions stay uncluttered.
