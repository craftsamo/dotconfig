# hand-painted

**Look.** Painted 2D game objects with controlled brushwork, warm material
variation and simple large value groups. Interpret "Hard-Painted" as this
style only when the client meant hand-painted; otherwise ask what differs.

**Prompt block.**
> Hand-painted 2D game asset, <item>, <palette>, broad painterly value
> groups, carefully painted edges, subtle brush marks, upper-left light,
> <prop perspective or front-facing UI>, isolated on flat <key colour>,
> no canvas background, no floor shadow, no lettering, no watermark.

**Avoid.** Oil-canvas backdrop, muddy silhouette edges, random grunge over
button label areas, noisy microtexture that disappears at use size.

**QA cues.** Paint remains within the cutout; bright/dark grounds reveal no
fringe. Material and brush scale are shared; panels have calm content areas.
