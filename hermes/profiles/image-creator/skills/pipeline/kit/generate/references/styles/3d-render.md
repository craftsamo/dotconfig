# 3d-render

**Look.** Two-dimensional renders of rounded stylized game objects, broad
bevels, restrained roughness and soft upper-left studio light. UI faces
the screen; props alone use the chosen world camera. No mesh is delivered.

**Prompt block.**
> A rendered stylized game asset, <item>, <palette>, tactile rounded bevels,
> broad readable forms, matte material, upper-left softbox highlight,
> <prop perspective or front-facing UI>, isolated on solid <key colour>,
> no cast ground shadow, no floor, no text, no watermark.

**Avoid.** Photoreal clutter, glass transparency that keys badly, depth of
field, floating ground planes, changing light direction, tilted UI chrome.

**QA cues.** Bevel width and lighting agree across categories; no halo on
light/dark grounds; highlights remain inside the silhouette. Do not call
the PNGs editable 3D models.
