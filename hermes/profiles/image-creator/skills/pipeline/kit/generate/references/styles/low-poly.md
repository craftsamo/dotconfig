# low-poly

**Look.** Faceted low-polygon game objects rendered as pictures: large
flat-shaded triangular planes, one flat shade per facet, a restrained
palette, soft upper-left light, no texture. Toy-like world props; UI
chrome is flat with a few bevel facets at most. No mesh is delivered.

**Prompt block.**
> Low-poly rendered game asset of <item>, <palette>, large flat-shaded
> triangular facets, one flat shade per facet, no texture, soft
> upper-left light, chunky readable form, <prop perspective or
> front-facing UI>, isolated on solid <key colour>, no floor, no cast
> ground shadow, no lettering, no watermark.

**Avoid.** Smooth subdivided surfaces, hundreds of tiny facets, glossy
reflections, wireframe overlays, facet sizes that differ wildly between
props, faceted text.

**QA cues.** Facet size and light direction agree across all props;
silhouettes read at 1x; highlights stay inside the silhouette; the PNGs
are never called 3D models.
