# Gradient glow

Full-bleed deep indigo with warm coral and violet light. Unframed, saturated,
expressive; text remains crisp and opaque over the atmosphere.

```css
:root { --surface: #211b4f; --ink: #ffffff; --accent: #ffb09b; }
.stage { background: radial-gradient(ellipse at 5% 0%, #ae503c, transparent 60%), radial-gradient(ellipse at 90% 100%, #663ac0, transparent 65%), var(--surface); }
.panel { background: transparent; }
.accent { background: linear-gradient(90deg, #ff9476, #dda2fa, #83e0ee); box-shadow: 0 0 24px #f49cca80; }
```
