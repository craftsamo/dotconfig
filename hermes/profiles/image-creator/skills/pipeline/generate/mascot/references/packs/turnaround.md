# turnaround — the model sheet (4)

The four views an animator, a 3D modeller or a video composition needs
to keep the character consistent: front, three-quarter, side, back. Same
neutral pose and expression in all four; the character stands, arms
slightly away from the body, feet visible. The front view repeats the
anchor on purpose — it is the row's reference for the other three.

| name | pose / expression / prop |
| --- | --- |
| front | standing, facing the viewer, neutral friendly expression, arms slightly away from the body |
| three-quarter | standing, turned 45° to the viewer's left, same neutral expression, arms slightly away from the body |
| side | standing, full profile facing the viewer's left, same neutral expression, the near arm slightly forward so the body's shape shows |
| back | standing, facing away from the viewer, the back of the head and body fully visible, arms slightly away from the body |
