# Flat minimal

Warm off-white, ink and a single vermilion mark. Flat, quiet, generous margins;
no panel or shadow. Do not add decorative glow.

```css
:root { --surface: #f6f4ee; --ink: #17202e; --accent: #c84b2b; }
.stage { background: var(--surface); }
.panel { background: transparent; }
.accent { background: var(--accent); }
h1 { font-weight: 700; letter-spacing: -0.02em; }
```
