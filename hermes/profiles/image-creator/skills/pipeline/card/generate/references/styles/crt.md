# CRT backdrop

Medium: an image seen on an old CRT television or VHS tape: a dusk seascape,
city lights or a retro scene with warm colour bleed, soft blur, horizontal
scanlines and a faint rolling tracking band; darker and calmer where the text
sits. No on-screen date stamp, channel number, logos or any text. The local
CSS owns the screen edge, vignette and actual text.
