# poses — the everyday set (8)

The poses a mascot is asked for first: a greeting, a success, a
question, a celebration, a setback, work in progress, a pointer for a
callout, and a sleep for an empty state. Full body unless the line says
otherwise. Props are written big, saturated and clear of the body's own
colours on purpose: on the emoji family every pale or small prop
vanished at display size.

| name | pose / expression / prop |
| --- | --- |
| wave | standing, one hand raised high in a wave, big open smile |
| thumbs-up | standing, one arm out with a large clear thumbs-up, confident grin, the other hand on the hip |
| thinking | standing, one hand at the chin, eyes up and to the side, one brow raised, a big saturated "?" floating beside the head clear of the body |
| celebrate | jumping with both arms up, eyes squeezed shut in joy, three large confetti pieces in the air beside the head |
| oops | standing, shoulders up, a sheepish smile, one hand behind the head, one big saturated sweat drop beside the temple |
| working | standing, sleeves rolled, holding a large wrench (or the tool the concept names) in both hands, focused expression |
| pointing | standing, one arm straight out to the viewer's right with the index finger pointing, looking the same way, eyebrows raised |
| sleeping | curled up on the ground, eyes closed, one large saturated "z" with a dark outline floating above the head |
