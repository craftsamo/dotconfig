# Motif return

Intent: state a short, recognizable melodic figure early, depart from it
(new material, or a `contrast`-like section), then bring the same figure
back near the end - a bookend structure. Suits a piece that needs to feel
"complete" rather than open-ended.

Score guidance: write the motif as a short, identifiable sequence of
`notes` (same relative pitches and rhythm, transposition/octave shift is
fine) on one track early in the score, include contrasting material in
the middle, then repeat the same relative-pitch/rhythm sequence again
near the end (it may combine with `ending: resolve` for a satisfying
close).

QA cue: locate the motif's first statement and its return by comparing
relative pitch/rhythm sequences (not exact MIDI values, since
transposition is allowed); a score with no identifiable repeated figure
is a mismatch to flag, not a passing motif-return cue.
