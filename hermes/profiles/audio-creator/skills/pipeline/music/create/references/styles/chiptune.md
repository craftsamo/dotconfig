# Chiptune

Achievable palette: `pulse` for the lead melody (the classic 8-bit lead
timbre), `triangle` for a simple bass line, `noise` for percussion-like
hits on strong beats, `fm-bell` used sparingly for a brighter accent
note. Favor short, quantized note durations, simple diatonic melodies and
a clear repeating bass pattern - the genre reads through simplicity and
repetition, not through any effect this schema cannot render (no bit-
crush, no arpeggiator, no portamento - none exist here).

Controls NOT available: no vibrato/portamento glide, no arpeggiator
automation (write out each arpeggio note explicitly if wanted), no
bit-crush/distortion.

Example adaptation: a chiptune app-opener might use `pulse` for a short
melodic fanfare, `triangle` for a two-note walking bass, and one `noise`
hit on the downbeat of each bar.

QA cue: confirm the lead track is actually `pulse` (not `sine`/`triangle`,
which read softer) and the bass is simple/repetitive; a soft, sine-led
score mislabeled chiptune is a mismatch to flag before approval.
