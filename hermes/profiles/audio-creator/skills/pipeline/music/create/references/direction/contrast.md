# Contrast

Intent: a clear A/B (or A/B/A) shift in character partway through - a
change in instrumentation, register or density, then usually a return or
a distinct close. Not a gradual ramp (`gradual-build`) and not a single
consistent texture (`steady`).

Score guidance: define a clear boundary bar where the active track set,
register (e.g. moving the melody an octave) or density changes noticeably
from the section before it. `bpm` and `key`/`meter` stay fixed for the
whole score (this schema has no mid-score tempo/key change); contrast is
expressed through instrumentation, register and density, not a claimed
tempo shift.

QA cue: identify the boundary bar and confirm the active track set or
register actually differs measurably on each side of it; a score with no
identifiable section boundary is a `steady` mismatch, not a passing
contrast cue.
