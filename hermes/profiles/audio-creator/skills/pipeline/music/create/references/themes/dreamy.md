# Dreamy

Mood: floating, soft-focus, slightly unresolved; suits an ambient/reflective
bed or a gentle scene transition, not a driving or percussive cue.

Waveform palette: sine/triangle sustained pads with slow attacks (achieved
through longer note durations and gentle velocity rather than an envelope
control this schema does not expose), fm-bell for sparse, widely-spaced
sparkle notes, restrained low-gain noise as air/texture only. Favor wider
or extended intervals and occasional unresolved (non-tonic) held notes over
tight, resolved harmony.

Not fixed: dreamy implies no forced tempo or key. `theme_detail`,
`direction` and `tempo` override any default implied here.

Adaptation example: a dreamy cue for a memory sequence might hold long
sine tones an octave apart with a single bell note every few bars; a
dreamy but slightly more active cue keeps the same sparse, held-note
character while increasing note count moderately, never adding a driving
rhythm section.

QA cue: verify the score favors sparse, held notes and gentle dynamics
(`velocity`) rather than dense, staccato writing; a busy, loud score
mislabeled `dreamy` is a mismatch to flag before approval.
