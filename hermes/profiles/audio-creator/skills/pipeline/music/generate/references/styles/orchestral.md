# Orchestral

Prompt vocabulary: strings section, brass, woodwinds, timpani/orchestral
percussion, cinematic dynamics, sweeping melodic lines. Favor named
orchestral sections over the bare word "orchestral" alone.

No guaranteed model behavior: a full, balanced orchestral mix (proper
section balance, articulation detail) is not guaranteed from a short text
prompt; treat the result as an approximation of the described
instrumentation, not a studio orchestral recording.

Example adaptation: "sweeping orchestral instrumental, string section
melody, subtle brass accents, timpani hits at key moments, cinematic
dynamics, no vocals".

QA cue: report whether the returned take actually contains the named
sections on playback (perceptually unverified without a listen) rather
than assuming a full orchestral texture from the prompt alone.
