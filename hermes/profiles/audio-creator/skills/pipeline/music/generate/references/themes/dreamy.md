# Dreamy

Mood: floating, soft-focus, slightly unresolved; suits an ambient or
reflective bed, not a driving or percussive cue.

Prompt vocabulary: reverberant pads, soft synth or bowed strings, distant
piano, airy texture, slow attacks, sparse arrangement. Favor spacious,
reverb-forward language and wide/unresolved harmony words over tight,
punchy phrasing.

Not fixed: dreamy implies no forced tempo or key. `theme_detail`,
`direction` and `tempo` override any default implied here.

Adaptation example: a dreamy memory-sequence cue might read "reverberant
soft synth pad, distant piano notes, airy and slow, sparse arrangement";
a slightly more active dreamy cue keeps the airy, reverberant language
while allowing a few more notes, never adding a driving beat.

QA cue: check the prompt actually names spacious/airy timbre words rather
than only the label `dreamy`; a busy, punchy prompt mislabeled `dreamy` is
a mismatch to flag before approval.
