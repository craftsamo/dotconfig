# Lofi

Prompt vocabulary: mellow piano or Rhodes, warm tape saturation/vinyl
crackle texture, laid-back drum groove, relaxed tempo feel, jazzy chords.
Favor "warm", "mellow" and "laid-back" language over bright/aggressive
words.

No guaranteed model behavior: vinyl-crackle/tape-hiss texture is a common
lofi signature but is not guaranteed to render from the word "lofi" alone
- name it explicitly if it matters to the brief.

Example adaptation: "lofi hip-hop instrumental, mellow Rhodes chords,
laid-back drum groove, warm vinyl crackle texture, relaxed tempo, no
vocals".

QA cue: report whether the returned take actually reads warm/laid-back on
playback versus a brighter, cleaner result; this is a perceptual check,
unverified without a listen, and should be flagged as such rather than
assumed from measurements.
