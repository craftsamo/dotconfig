# Electronic

Prompt vocabulary: synth lead/pad, programmed drum pattern, bass synth,
clean production, steady rhythmic pulse. Favor concrete synth-instrument
words over the bare genre label alone.

No guaranteed model behavior: "electronic" spans many sub-styles (house,
techno, synthwave, IDM); naming sub-genre words in the prompt narrows the
result more reliably than the bare word "electronic" alone. The backend
is not guaranteed to match a named sub-genre precisely.

Example adaptation: "upbeat electronic synth-pop instrumental, driving
programmed drums, bright synth lead, steady bass, no vocals".

QA cue: report the requested sub-style language explicitly in the
proposal so a mismatch (e.g. asked techno, got ambient-electronic) is
easy to spot in QA rather than accepted as close enough.
