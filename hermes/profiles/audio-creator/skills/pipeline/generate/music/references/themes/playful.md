# Playful

Mood: light, bouncy, a little mischievous; suits a UI/app opener or a
lighthearted montage bed, never a serious or tense scene.

Prompt vocabulary: pizzicato strings, marimba/xylophone, ukulele or
plucked guitar, light bouncy percussion (shaker, light kit), short
staccato phrasing. Favor short, punchy note language over sustained pads
in the prompt.

Not fixed: playful implies no forced tempo or key. `theme_detail`,
`direction` and `tempo` override any default implied here.

Adaptation example: a playful app-opener might read "bouncy marimba and
pizzicato strings, light shaker percussion, upbeat 120 BPM feel"; a
gentler playful underscore keeps the same bouncy, staccato timbre words
at a slower tempo description instead.

QA cue: check the prompt actually names bouncy/staccato instrument words
rather than only the label `playful`; a prompt built from slow sustained
pad language mislabeled `playful` is a mismatch to flag before approval.
