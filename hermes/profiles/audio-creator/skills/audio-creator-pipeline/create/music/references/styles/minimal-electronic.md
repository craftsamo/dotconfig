# Minimal electronic

Achievable palette (the score schema's five instruments only): `pulse` for
a plain, repetitive lead/arpeggio figure, `sine` for a simple sub bass,
sparse `noise` for a soft hat-like texture at low gain. Keep track count
low (2-4) and note patterns simple/repetitive - this style is defined by
restraint, not by any instrument this synthesizer cannot produce (no
sampled drum kit, no sidechain compression, no filter sweep - none of
those exist in this schema).

Controls NOT available: no drum samples, no automation/LFO, no filter
cutoff sweep over time, no sidechain ducking. Describe the pattern through
note placement (regular, repetitive rhythmic cells) instead.

Example adaptation: a minimal-electronic loader/opener might use one
`pulse` track playing a repeating 4-note figure plus one `sine` bass note
per bar, no `noise` at all - still recognizably minimal.

QA cue: track count and note-pattern repetition are the actual evidence
of "minimal"; a busy score with many simultaneous tracks mislabeled
minimal-electronic is a mismatch to flag before approval.
