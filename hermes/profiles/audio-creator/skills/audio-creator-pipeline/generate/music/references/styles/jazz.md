# Jazz

Prompt vocabulary: piano or vibraphone, upright bass, brushed drums, swung
rhythm, extended/jazz-chord harmony. Favor named jazz instrumentation and
"swung"/"walking bass" language over generic terms.

No guaranteed model behavior: swing feel and improvisation-like phrasing
are stylistic signatures the backend is not guaranteed to nail precisely;
treat any resulting "jazz" character as approximate, not a verified
performance.

Example adaptation: "smooth jazz instrumental, piano and vibraphone,
walking upright bass, brushed drums, relaxed swung feel, no vocals".

QA cue: report whether the returned take actually reads as swung/jazz
voicing on playback - perceptually unverified without a listen; a
straight, unswung result mislabeled jazz is a mismatch to flag.
