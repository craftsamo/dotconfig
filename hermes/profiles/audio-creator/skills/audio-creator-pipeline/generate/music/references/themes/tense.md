# Tense

Mood: uneasy, anticipatory, unresolved; suits a suspense/waiting bed or a
buildup underscore, not a resolved or celebratory cue.

Prompt vocabulary: low drone or pedal tone, dissonant strings, sparse
percussive ticks, tremolo, minor/dissonant harmony language, restrained
dynamics building slowly. Favor repetition and dissonance words over
consonant, flowing melody language.

Not fixed: tense implies no forced tempo or key. `theme_detail`,
`direction` and `tempo` override any default implied here; a slow tense
cue (dread) and a fast tense cue (panic) are both valid.

Adaptation example: a tense waiting-room cue might read "low string
drone, dissonant tremolo, sparse ticking percussion, no resolution"; a
tense chase-adjacent cue keeps the dissonant, repeating language while
adding faster tempo/rhythmic description instead.

QA cue: check the prompt actually withholds resolution language (avoid
"resolves", "bright", "major" unless `ending: resolve` was requested) and
favors repetition/dissonance; a consonant, resolved prompt mislabeled
`tense` is a mismatch to flag before approval.
