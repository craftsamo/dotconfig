# Archived Creator technics

Creator's former production technics and the legacy references that routed to
them, kept for reading only. No profile loads this directory: nothing here is a
skill source, and nothing here is dispatched.

- `creator-*/` — the 19 former technics, unchanged.
- `creator-legacy/` — Creator's legacy produce/verify/delivery contract and its
  capability table.
- `assistant-legacy/` — the Assistant's legacy Plan, Execute and QA references
  that mapped to those technics.

Five are source material for hands leaves: `creator-svg-diagram`,
`creator-pixel-art` and `creator-generated-image` (image-creator),
`creator-brand-asset-sourcing` (folded into image-creator's `source-icon`) and
`creator-pixel-video` (video-creator). A new capability is a hands leaf, never a
revived technic. Contract: [`docs/broker.md`](../../docs/broker.md) "Legacy
routes".
